## 1. 背景と実験設定

Cosmos Policy は EDM デノイジングプロセス中に**アクション（T=5）と将来画像（T=7,8,9）を同時に生成する**。  
アクション検証（[results_01](results_01_action_denoising.md)・[results_02](results_02_action_features.md)）と同一の手法を画像生成ラテント空間に適用した。

### RoboCasa の Latent Sequence 構造 (state_t=11)

```
T=0:  blank          T=5:  action          ← 生成対象
T=1:  curr proprio   T=6:  future proprio  ← 生成対象
T=2:  curr wrist     T=7:  future wrist    ← 生成対象（画像）
T=3:  curr primary   T=8:  future primary  ← 生成対象（画像）★メイン解析対象
T=4:  curr secondary T=9:  future secondary← 生成対象（画像）
                     T=10: value           ← 生成対象
```

### 実験設定

| 項目 | 内容 |
|------|------|
| 対象 T インデックス | T=7（future_wrist）, T=8（future_primary）, T=9（future_secondary） |
| 比較対象 | T=5（action）, T=3（curr_primary、固定入力） |
| エピソード数 | 5 |
| デノイジングステップ | 5（k=0〜4、σ: 80→42.3→21.0→9.6→4.0） |
| Policy 呼び出し回数 | 160 |
| プローブ層 | Block-0, 4, 9, 13, 18, 22, 27 |
| 使用 GPU | NVIDIA RTX 4090 × 2（EGL: GPU 0、モデル: GPU 1） |

### セットアップ時の主な課題と解決

| 課題 | 原因 | 解決 |
|------|------|------|
| EGL 初期化失敗 | Singularity 内で NVIDIA EGL ICD 未登録 | `__EGL_VENDOR_LIBRARY_FILENAMES` で明示指定 |
| CUDA OOM（GPU 0） | qwen3-vllm が GPU 0 を 21 GiB 占有 | モデル起動前に `torch.cuda.set_device(1)` |
| T5 埋め込みキャッシュ OOM | `cuda:0` 固定 | `worker_id=1` を明示指定 |
| EGL と CUDA の競合 | CUDA 初期化後は GPU 1 のみ列挙（DRI 権限外） | 環境作成（EGL 初期化）をモデルロード前に実行 |

## 2. テーマ 1 相当: ラテントノルム推移

各デノイジングステップでの x̂₀ の L2 ノルム（160 policy calls 平均）:

| 位置 | T インデックス | k=0 | k=4 | 変化 |
|------|--------------|-----|-----|------|
| future_wrist | T=7 | 118.26 ± 10.14 | 118.73 ± 10.52 | +0.4% |
| future_secondary | T=9 | 104.79 ± 3.05 | 104.97 ± 2.88 | +0.2% |
| **future_primary** | **T=8** | **99.86 ± 3.94** | **100.09 ± 3.88** | **+0.2%** |
| curr_primary (固定) | T=3 | 99.21 ± 3.13 | 99.21 ± 3.13 | **0%** |
| action | T=5 | 49.08 ± 4.04 | 49.31 ± 4.11 | +0.5% |

**所見**:
- 画像ラテントのノルムはアクションラテント（≈49）の**約 2 倍**（≈100〜118）→ 画像の潜在空間はアクションより密な情報量
- future_wrist（118）> future_secondary（105）≈ future_primary（100）: 手首カメラが最も高密度（局所的・詳細）
- curr_primary（T=3）のノルムは全ステップで完全に一定（delta=0）→ 固定条件付けトークンとして期待通りの挙動。モデルが既存観測に「書き込み」を行わないことの直接証拠

→ プロット: `theme_image_results/image_theme1b_latent_norm.png`

## 3. テーマ 1-A: 連続ステップ間のラテント変化量 ||Δx̂₀||₂

各遷移での delta ノルム（160 policy calls 平均 ± std）:

| 位置 | k=0→1 | k=1→2 | k=2→3 | k=3→4 | Δk4/Δk1 比 |
|------|--------|--------|--------|--------|------------|
| future_wrist (T=7) | 1.495 ± 0.551 | 2.530 ± 1.684 | 3.931 ± 2.657 | **5.366 ± 3.110** | 3.6× |
| future_secondary (T=9) | 1.158 ± 0.184 | 1.509 ± 0.669 | 1.986 ± 1.286 | **2.656 ± 2.013** | 2.3× |
| future_primary (T=8) | 1.181 ± 0.190 | 1.553 ± 0.640 | 2.097 ± 1.180 | **2.916 ± 1.897** | 2.5× |
| **action (T=5)** | **0.896 ± 0.069** | **1.095 ± 0.266** | **1.400 ± 0.669** | **1.782 ± 1.163** | **2.0×** |
| curr_primary (T=3) | 0 | 0 | 0 | 0 | — |

**所見**:

1. **「Confidence-to-Commitment」はアクションだけでなく画像生成にも普遍的**: 全画像位置（T=7,8,9）で k=0→1 < k=1→2 < k=2→3 < k=3→4 の単調増加パターンが成立。EDM デノイジングの本質的挙動がラテント空間全体に貫通している。

2. **画像の変化量はアクションの 1.6〜3.0 倍**: k=3→4 の最終ステップで future_wrist（5.37）がアクション（1.78）の **3.0 倍**の変化量。同一デノイジングプロセス内でも画像ラテントがより大きな「Commitment」を行う。

3. **future_wrist が最大変化（Δk4/Δk1 = 3.6×）**: 手首カメラ画像は最も急峻な変化率。把持の精密な空間的配置を直接反映するため、低ノイズ段階での高精度な細部決定が特に重要。

4. **curr_primary のゼロ変化**: 固定入力（現在の観測画像）は全ステップで変化量ゼロ。モデルが条件付けトークンを書き換えない（マスクされた生成）ことが定量的に確認された。

→ プロット: `theme_image_results/image_theme1a_delta_norm.png`

## 4. テーマ 1-C: FFT スペクトル解析（空間周波数）

将来画像ラテント（T=8、future_primary）の 2D FFT 半径平均スペクトル（k=0 vs k=4 比較）:

**観察**: FFT スペクトルの変化は k=0→k=4 の間で生じるが、明確な「低周波→高周波の順次精緻化」パターンは 5 ステップの範囲では顕著でない。最終ステップでわずかに高周波成分が増加する傾向が確認される。アクション検証（§4.4 参照）と類似の結果。

**解釈**: 画像ラテント空間での Coarse-to-Fine（空間周波数的）精緻化は限定的であり、むしろ Δノルム急増に見られるように「信号強度の段階的確立」という形での精緻化が主要なメカニズム。

→ プロット: `theme_image_results/image_theme1c_fft_spectrum.png`

## 5. テーマ 2 相当: 隠れ状態解析（画像トークン vs アクショントークン）

### 5.1 線形プロービング（スキルフェーズ予測）

各 DiT ブロックの出力（空間平均後の特徴ベクトル）を用いた Ridge 線形回帰による call_idx 予測精度（k=0〜4 別）:

**action トークン (T=5)**:

| Block | k=0 | k=2 | k=4 | 最大値 |
|-------|-----|-----|-----|--------|
| Block-0 | 0.394 | 0.356 | 0.363 | 0.394 |
| Block-4 | 0.356 | 0.338 | 0.506 | 0.506 |
| Block-9 | 0.625 | 0.550 | 0.575 | 0.625 |
| Block-13 | 0.575 | 0.575 | 0.538 | 0.594 |
| **Block-18** | **0.638** | **0.638** | **0.644** | **0.644** |
| Block-22 | 0.563 | 0.575 | 0.575 | 0.575 |
| Block-27 | 0.569 | 0.581 | 0.581 | 0.588 |

**future_primary トークン (T=8)**:

| Block | k=0 | k=2 | k=4 | 最大値 |
|-------|-----|-----|-----|--------|
| Block-0 | 0.369 | 0.363 | 0.369 | 0.388 |
| Block-4 | 0.350 | 0.319 | 0.281 | 0.350 |
| Block-9 | 0.438 | 0.444 | 0.456 | 0.456 |
| Block-13 | 0.463 | 0.456 | 0.450 | 0.469 |
| **Block-18** | **0.563** | **0.563** | **0.556** | **0.563** |
| Block-22 | 0.556 | 0.563 | 0.525 | 0.563 |
| Block-27 | 0.588 | 0.575 | 0.556 | **0.594** |

**所見**:

1. **action トークンが future_primary より一貫して高い精度**: action（max 0.644）> future_primary（max 0.594）。Cosmos Policy がアクション生成を主タスクとして設計されており、画像生成は副産物的な性格を持つことと整合。

2. **Block-18 が両トークンで最高精度**: action（0.644）・future_primary（0.563）ともに Block-18 付近で最高値。この層がタスク状態の時間的進行に最も敏感な中間表現を形成。

3. **future_primary の精度がアクションより低い**: 将来画像のラテント表現は action より「今のフェーズ」情報を明示的に持たない。画像は環境の視覚的結果（visual outcome）、アクションは制御意図（control intent）を直接符号化するため。

→ プロット: `theme_image_results/image_theme2_linear_probe.png`, `image_theme2_probe_stats.json`

### 5.2 Linear CKA（アクション vs 画像トークンの表現類似度）

**action (T=5) vs future_primary (T=8) の CKA**:

| Block | k=0 (σ=80) | k=1 | k=2 | k=3 | k=4 (σ=4) |
|-------|-----------|-----|-----|-----|-----------|
| Block-0 | **0.9999** | 0.9999 | 0.9944 | 0.9171 | 0.6592 |
| Block-4 | 0.9651 | 0.9587 | 0.7889 | 0.2559 | 0.0894 |
| Block-9 | 0.5959 | 0.5546 | 0.4711 | 0.2330 | 0.0959 |
| Block-13 | 0.3517 | 0.3489 | 0.3337 | 0.2922 | 0.1767 |
| Block-18 | 0.5259 | 0.5268 | 0.5264 | 0.5396 | **0.5966** |
| Block-22 | 0.5338 | 0.5341 | 0.5357 | 0.5417 | 0.5547 |
| Block-27 | 0.2945 | 0.2968 | 0.3043 | 0.3174 | 0.3341 |

**所見**:

1. **純ノイズ状態（k=0）での完全一致（CKA=0.9999）**: デノイジング開始時点（σ=80）では action と future_primary の Block-0 表現がほぼ完全に同一。同一の拡散プロセスが全 T インデックスを処理するため、ノイズ段階では全ポジションが近似した特徴空間に存在。

2. **デノイジング進行とともに急速に分化**: k=0→k=4 で CKA が 0.9999→0.6592 (Block-0)、0.9651→0.0894 (Block-4) と急激に低下。特に Block-4 での k=4 CKA ≈ 0.09 は、アクションと画像の内部表現が**ほぼ直交するほど分化**することを示す。

3. **Block-18/22 での安定した中程度 CKA（≈0.53〜0.60）**: 深い中間層では最終ステップでも CKA が 0.53〜0.60 を維持。タスク意味的表現は両トークン間で共有されており、「どのタスクの何フェーズか」という高次情報が action・image 両チャンネルに冗長に符号化される。

4. **Block-27 での最小 CKA（k=4: 0.33）**: 最深ブロックでアクションと画像の表現が最も分離。**アクション生成と画像生成の「最終確定」処理は別々の表現空間で独立に行われる**。

→ プロット: `theme_image_results/image_theme2_cka.png`, `image_theme2_cka_stats.json`

## 7. 主要な新知見

1. **「Confidence-to-Commitment」の普遍性**: アクション生成で観察された単調増加パターンは、将来画像ラテント（T=7,8,9）でも例外なく成立する。EDM デノイジングの本質的挙動が、アクションと画像を問わず一貫して現れる。

2. **「共同生成の開始点は完全な一致」**: k=0（純ノイズ状態）では action トークンと future_primary トークンの Block-0 表現が CKA=0.9999 で完全一致。デノイジングが進むにつれてアクション固有・画像固有の表現へと分化する過程が定量的に追跡できた。

3. **「画像は固定入力より共同生成先と相関する」**: curr_primary（現在観測、固定）の action との k=0 CKA は 0.80 だが、future_primary（未来画像、共同生成）は 0.9999。共同生成される未来像はアクションと不可分に結びついて生成されることが確認された。これは Cosmos Policy の「世界モデルとしての性格」——アクションと整合する未来像を同時に計画する——の直接証拠。

4. **「アクションが画像よりタスク進行を明示的に符号化」**: 線形プロービングで action トークン（Block-18: 0.644）が future_primary（0.563）を上回る。アクション生成（制御意図）はタスクフェーズを直接的に表現するが、画像生成（視覚的結果）は間接的・暗黙的に表現する。
