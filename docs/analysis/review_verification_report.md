全体を精読し、数値の相互整合も検算しました。**前回からは劇的に改善しています**——0%成功率（計測がモデルを壊していた問題）はT1でmax|Δ|=0.00・fingerprint一致まで詰めて解消、リークはfold内PCAで除去、pad未マスクはT3で正しくFAIL検出、そして§3.Aで線形ガウスnullを置いた結果として「単調増加はスケジュール由来でモデル固有ではない」と**自分に不利な事実を正直に報告**しています。ここは高く評価します。

その上で、厳しく見ると**結論部が自らの証拠と矛盾しており、加えて新しい数値の自己矛盾と、設計意図を満たしていない検証が複数**あります。以下、重い順に。

## 1. 最重大：総合結論が §3.A の自分の証拠と矛盾している

これが最大の問題です。

§3.A本文（L100-104）はこう結論しています：schednormの単調増加は**線形ガウスnullも同様に示す**（0.051→0.485）、しかも実測は最終ステップでnullの**48%しか変化しない**（0.205 vs 0.425）。つまり「後半ほど大きく変化する」という素朴なConfidence-to-Commitmentの**直接証拠にはならない**——ここまでは正しく、誠実です。

ところが「統合解釈」（L347-）では、同じ§3.Aを**「証拠1」として引用し、「スケジュールでは説明不能なモデル固有の効果」**と書いています。§3.Aが「スケジュールで説明できる（nullも増える）」と結論したのに、統合部では真逆の主張の根拠にしている。**同一ファイル内で§3.Aの結論が反転しています。**

さらに致命的なのは、統合部L352の数値「0.192→0.266」が**レポートのどの表にも存在しない**ことです。§3.A表のschednormは0.066→0.234、§4のCohen's d節も「0.0665 vs 0.2339」で一致していますが、0.192も0.266もどこにもない。旧ドラフトの残骸か捏造で、いずれにせよ**結論の根拠数値がトレースできません**。

**本質的な概念の混同**もあります。生き残った頑健な発見は2つですが、これらは別物です：
- (a) **行動出力** x̂₀ の変化：nullより**小さい**（後半で抑制）。
- (b) **中間層の内部表現**：k=4で急再編（PR崩壊・CKA低下）。

(a)はむしろ「commit=大きく変化」の直感に反し、(b)は「入力がクリーンになったので特化した」だけかもしれない別現象です。統合部はこれを一本の「Confidence-to-Commitment」に溶接していますが、**誠実な結論は「行動出力レベルではcommitmentは棄却、中間層で表現の再編が最終ステップに起きる」**であるべきで、両者を同じ機構と呼ぶ根拠は示されていません。

## 2. 数値の自己矛盾（バグではなくラベリング／転記の問題）

### 2.1 ‖D_θ‖ のCVが 0.189% と 7.62% で両立不能

§3.C は「noise_pred (=‖D_θ‖) CV=0.189%」（L146）と書く一方、F_θ表（L158）では ‖D_θ‖/√d=0.775 の行にCV%=7.62% を並べています。ところが c_skip≈0・c_out≈0.5 なので **D_θ ≈ 0.5·F_θ**。定数倍はCVを変えないので、**‖D_θ‖のCVは‖F_θ‖と同じ7.62%でなければならず、0.189%にはなり得ません。**

種明かしは検算で確定します：標準ガウスのノルムのCVは 1/√(2d)。d=137,983 なら 1/√(2·137983)=**0.190%**。報告の0.189%と一致。つまり**「0.189%の量」は白色化された単位分散の学習ターゲット**であって、D_θではありません。旧「std=0.701」問題はこの**白色化ターゲット**についての話で、F_θ解析は**別の、意味のある量**です。結論（F_θに状態依存構造がある）自体は妥当ですが、レポートは「noise_pred = D_θ」という**誤った同一視**を書いており、「何が空虚な量で何が意味のある量か」が読者に伝わりません。ここは明示的に分離して書き直すべきです。

### 2.2 その他の不整合
- ファイル数：L67「61ファイル」 vs L677「46ファイル」。P10で潰すはずの帳簿ズレが残存。
- σ_data：§3.Aのnullは 0.443（実測std）、§3.CのEDMは 0.5。別量とはいえ、nullを実測0.443で組むとモデル想定0.5と食い違い、null較正が微妙にズレます。

## 3. 設計意図をまだ満たしていない検証

### 3.1 T8（固定入力コントロール）を飛ばしたのに、それが必要な場所でgripperが95%出ている

T8は「プローブが**行動予測**を読んでいるのか、それとも**固定の観測入力（条件付け）**を読んでいるのか」を切り分けるための唯一の統制でした。これが「形式的テスト未実施」で後回し（L62-64）。

そして§3.Gのgripperプローブは**全層・全ステップで95%+**（L295）。もしBlk-0のk=0（σ=80、入力がほぼノイズ）でも95%取れているなら、それはノイズ化された行動潜在ではなく、**固定入力（proprio/観測）から漏れているラベルを読んでいる**強い兆候です。旧results_03でも「curr_primary固定入力でも同精度」と同じ症状が出ていました。**T8はまさにこの症状を検出するための統制**なのに、それを飛ばしたまま§3.Gを「✅完了」とし、gripperの高精度を「表現全体に強くエンコード」と解釈している。gripperコマンドは低エントロピー・自己相関の強い信号なので、相関する任意の特徴（=条件付け）から高精度で当たるのは当然で、「表現への符号化」の証拠としては弱い。**T8を実行するまでgripper結論は保留すべき**です。

### 3.2 §3.G の照合（T6）が3つの変更を交絡させている

新プローブは (i) fold内PCA、(ii) Ridge→LogisticRegression、(iii) n_comp 50→30 を**同時に**変えています。中間層で+0.17〜0.21の改善を全部「Global PCAが中間層情報を抑圧していた」に帰属（L280-284）していますが、これは分離できていません。

決定的な違和感：**リーク除去は普通は精度を下げます**（テストがtrainに漏れる＝楽観バイアス）。ところが中間層は**上がった**。これは改善の主因がリーク除去ではなく**分類器の入れ替え（閾値化Ridge→LR）**である可能性が高いことを示します。T6は本来「ラベル定義／PCA有無／run差」に分解する設計でしたが、**推定器の変更という第4の交絡を分解していない**。「根本原因＝Global PCA」は未証明です。

### 3.3 PRの「崖」の正体を詰め切れていない

PR は k=0,1,2 でほぼ完全平坦（55.8）→ k=3 微減 → k=4 で崖（18.4）。設計§3.Dは**中間σを挿入して「崖か、σの滑らかな関数か」を切り分ける**ことを求めましたが、実施されていません。追加した§5ランダム初期化nullは「nullは崖を示さない」を示しますが、**ランダムモデルはそもそもデノイズしない**ので、σ依存構造を出さないのは自明——「崖が学習固有か」の弱い証拠にしかならず、「崖か滑らかか」には答えていません。T5（捕捉ハッシュ）は捕捉衛生を確認しただけで、機構の切り分けではない。この設計項目は未完了です。

### 3.4 §3.J（J-b）が「アテンション寄与」ではなく「ノルム成長」を測っている

J-bは `‖feat(l+1)−feat(l)‖/‖feat(l)‖` を採用し、0→4で**8.74**、22→27で7.20。しかしBlk-0のノルム≈16.7、Blk-4≈146（旧results_01）なので、この8.74は**ブロック間のノルム成長そのもの**でほぼ説明できます（(146−16.7)/16.7≈7.7〜9.7）。つまりこの指標はMLP・LayerNorm・スケール変化を全部含み、**アテンション寄与を分離していない**。設計のJ-bは「‖attn出力‖/‖residual‖ 比」でアテンションを**分離**することを意図していました。実装は残差経路の情報流ではなく層間スケーリングを測っており、「初期処理層＋最終出力層が最大」という読みは構造の読み込みすぎです。J-bは意図した量になっていません。

### 3.5 §3.B の「C2F積極的棄却」は4点への過剰解釈

重心は 0.155→0.167→0.148→0.150 の**非単調**（上→下→微増）。§3.Bは置換検定で「k依存性は有意（p<0.0001）」、§4は「Spearman ρ=−0.600, p=0.400（非有意）」——**同一レポート内で片方が有意・片方が非有意**。矛盾ではない（置換は任意の差、Spearmanは単調傾向で4点では無力）ものの、「C2Fは検出力不足でなく積極的に逆方向」という強い主張は、**4点の傾き**（それも高い1点k=1→2に引きずられた負の傾き）に依存しています。誠実な言い方は「C2F傾向は検出されず、重心はほぼ平坦（≈0.15）」まで。「積極的に逆」は言い過ぎです。加えて、スカラー重心は低周波帯**内部**での再配分に鈍感で、設計が意図した半径方向パワー再配分を取りこぼしている可能性があります。

### 3.6 d_proxy=71 は効果量ではない

§4の `d_proxy=(1−CKA)/SE_bootstrap=71.2` はCohen's dではなく「点推定がCKA=1から何SE離れているか」で、ブートストラップSEが小さければいくらでも巨大になります。「統計的変動を圧倒的に上回る効果」と提示するのは**カテゴリーエラー**。CKAが1.0→0.73という0-1スケールの変化自体が解釈可能な効果なので、SEで割って71と称するのは誤誘導です。Cohen's dの隣に並べるべきではありません。

（関連して、PR dropのCohen's dは Blk-0=1.94「Large」がPR変化+0.14（1%）、Blk-4=1.90「Large」がPR変化34。**同じ"Large"ラベルが実質240倍違う変化に付く**。統計的効果量≠実務的有意性で、生の絶対量と併記しないと誤読を招きます。）

### 3.7 §3.H「モデルはpadをマスクしない（97%がpadに乗る）」は検証不足

L481-487で「DiTがkey_padding_maskを渡さず、512全体へのunmasked softmaxを計算、実トークンは3%」と断定し、「pad埋め込み寄与は学習で抑制されていると推測」で締めています。これは**striking claimなのに検証が一行の推測**。T2は小ケースのsoftmax数値一致を見ただけで、この97%-on-pad状況を検証していません。可能性として (a) pad位置のvalueがほぼゼロで効かない、(b) フックが取り逃したattention bias/maskがどこか（T5エンコーダ側等）にある、が切り分いていません。**フック再構成attention·V と モデル実出力の直接照合**をしない限り、「モデルはマスクしない」は未確定です。

## 4. Run混在とprovenance

レポートは少なくとも**4つの異なるrun**にまたがっています：特徴/プローブ（1108call, 60%）、自己注意v2（1128call, 58%）、F_θ（323call, 15ep）、null（320call, 10ep）。§3.D/E/Kの「Cross-Analysis Agreement」は1108runで自己完結しており良いのですが、**統合解釈は§3.I（1128run）と§3.F/G（1108run）を混ぜて**います。設計§1.1は「cross-analysis主張ではrun_id共有を明記」を要求しました。どの証拠がどのrun由来かの明示が統合部にありません。またF_θ（15ep）とnull（10ep）は小標本で、320サンプルの2048次元共分散からのPR推定の不確実性（CI）が付いていません。

## 5. 総括と優先アクション

**誠実さと工学的完成度は本物**です。特に§3.Aで自分に不利なnull結果を正直に出した点、T1/T3を設計通りにPASS/FAILさせた点は、前回から質的に別物です。問題は「良い部品を組み上げた結論」が部品の示す向きと食い違っていることです。

優先順に：

1. **統合結論を書き直す**。§3.Aの正しい結論（行動出力レベルのcommitmentは**棄却**、nullより小変化）を反映し、生き残る主張は「中間層(4/9/13)がk=4で表現を再編する」に限定。幻の数値0.192→0.266を削除。「Confidence-to-Commitment」という名称が(a)出力変化と(b)内部再編のどちらを指すかを定義し直す。
2. **§3.CのD_θ/F_θのラベルを分離**。0.189%=白色化ターゲット（1/√(2d)で検算一致）、7.6%=F_θの状態依存変動、と明記。「noise_pred=D_θ」の誤同一視を撤回。
3. **T8を実行**してから§3.Gのgripper（特に浅層・高σでの95%）を解釈。条件付けからの漏れを排除できるまでgripper結論は保留。
4. **T6を推定器変更まで分解**（Ridge→LRの寄与を単独で測る）。リーク除去が精度を上げた逆説を説明する。
5. **PRの崖に中間σを挿入**（設計§3.D）。ランダムnullは崖の証拠にならないと明記。
6. **J-bをアテンション/残差比に置換**（現状はノルム成長を測っている）。
7. d_proxyをCohen's dの隣から外す。§3.Bは「重心ほぼ平坦、C2F傾向なし」に表現を弱める。
