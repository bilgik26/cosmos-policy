# 自己注意（Self-Attention）解析

**各出力トークンが入力画像・proprio のどの部分に注目しているかの定量化**  
**日付**: 2026-06-28 | **タスク**: PnPCounterToCab | **エピソード**: 3 | **Policy calls**: 96

## 概要

Cosmos Policy 2B DiT が **アクション・将来画像・将来 proprio・状態価値** を生成する際、  
**入力画像と入力 proprio のどの部分に注目しているか** を自己注意（Self-Attention）の重みから定量化した。

---

## 1. 実験設定

| 項目 | 値 |
|------|-----|
| タスク | PnPCounterToCab (RoboCasa) |
| エピソード数 | 3 |
| 総 policy call 数 | 96 |
| デノイジングステップ数 | 5 (σ = 80.0, 42.3, 21.0, 9.6, 4.0) |
| 解析対象ブロック | [0, 4, 9, 13, 18, 22, 27] (28 層中 7 箇所) |
| 注意フックの対象 | 各ブロックの `self_attn.compute_attention` |

### 1.1 Latent Sequence 構造（state_t=11）

```
T=0: blank         T=5:  action         ← デノイジング対象（出力）
T=1: proprio       T=6:  future_proprio  ← デノイジング対象（出力）
T=2: curr_wrist    T=7:  future_wrist    ← デノイジング対象（出力）
T=3: curr_primary  T=8:  future_primary  ← デノイジング対象（出力）
T=4: curr_secondary T=9: future_secondary← デノイジング対象（出力）
                   T=10: value           ← デノイジング対象（出力）
```

### 1.2 トークン構造

- patch_spatial=2、H=W=28 → 各 T 位置 = **14×14 = 196 トークン**
- 全シーケンス長: S = 11 × 196 = **2156 トークン**
- モデル: 2B DiT（16 heads、head_dim=128、28 ブロック）

### 1.3 注意重みの抽出方法

FlashAttention は重みを返さないため、`compute_attention(q, k, v)` にフックして  
Q・K を取得し、`softmax(Q @ K.T / sqrt(d))` を手動計算した。  
全シーケンスに対する softmax で正規化されており、定性的に正確な値。

### 1.4 集計方法

- 各 (block_idx, k_step) の注意行列: **96 policy call 分を平均**
- T 位置別注意行列 [11×11]: 出力 T が入力 T 全体へ向ける注意重みの平均
- 空間ヒートマップ [14×14]: 特定 (t_out, t_in) ペアの注意を空間的に集計

## 3. 分析 B: 空間的注意ヒートマップ

### 3.1 空間的注意の均一性（CV 値: 大 = 特定領域に集中）

Block 18、k=4 における 14×14 ヒートマップの変動係数（CV）:

| 出力 → 入力 | CV | 最大注意値 | ピーク位置 | 解釈 |
|------------|-----|-----------|-----------|------|
| **action → curr_wrist** | **1.016** | 0.00574 | (13, 5) 底辺 | 極度に集中（ハンドや物体が見える領域） |
| **action → curr_primary** | **1.007** | 0.00110 | (6, 10) 中右 | 高度に集中（物体の位置？） |
| action → curr_secondary | 0.527 | 0.00199 | (0, 8) 上部 | 中程度の集中 |
| future_wrist → curr_wrist | **0.358** | 0.00457 | (13, 5) | 比較的均一（全体参照） |
| future_primary → curr_primary | **0.288** | 0.00400 | (11, 9) | 最も均一（シーン全体を参照） |
| future_secondary → curr_secondary | **0.314** | 0.00598 | (11, 4) | 均一 |
| value → curr_primary | 0.616 | 0.00051 | (4, 10) | 中程度の集中 |
| future_proprio → curr_wrist | 0.743 | 0.00277 | (13, 5) | やや集中 |

### 3.2 主要な発見: Action トークンの空間的集中

**action → curr_wrist** での CV=1.016 という非常に高い値は:
- アクション生成時、ロボットの **手首カメラ画像の特定領域**（画像底辺：行 13、列 5）に集中して注目
- この領域はロボットのグリッパーと把持対象物が写る部分と一致
- つまり、**アクションはグリッパー周辺の視覚情報を強く参照**して生成される

**future_primary → curr_primary** での CV=0.288（最低）:
- 将来の三人称視点画像を生成するとき、現在の三人称視点画像 **全体を均等に参照**
- 「シーン全体を見て次のシーンを予測」する振る舞い

## 4. 分析 C: デノイジングステップ不変性

Block 18 における k=0〜4 の注意行列の最大変化量: **0.0000378**

| ステップ | action→proprio | future_primary→curr_primary | future_wrist→curr_wrist |
|--------|----------------|---------------------------|------------------------|
| k=0 (σ=80.0) | 0.000980 | 0.001694 | 0.001496 |
| k=1 (σ=42.3) | 0.000979 | 0.001694 | 0.001495 |
| k=2 (σ=21.0) | 0.000976 | 0.001695 | 0.001493 |
| k=3 (σ=9.6) | 0.000972 | 0.001694 | 0.001489 |
| k=4 (σ=4.0) | 0.000965 | 0.001696 | 0.001487 |

**→ 注意パターンはデノイジングステップに対してほぼ完全に不変**

これは以下を示唆する:
- 自己注意による「**どこを見るか**」はデノイジング開始時点で確立される
- 入力観測（T=1〜4）が固定されているため、注意先も固定的
- デノイジングの各ステップで「**何を生成するか**」（content）は変化するが、「**どこから情報を得るか**」（source）は変化しない

## 5. 総合まとめ

### 5.1 出力トークン別の注意戦略

| 出力トークン | 主な注意先 | 空間的均一性 | 解釈 |
|------------|----------|------------|------|
| **action** | proprio (1位) + wrist (2位) | **集中型** (CV≈1.0) | 固有感覚+グリッパー視点の局所情報から制御命令を生成 |
| **future_proprio** | proprio (1位) | 中程度集中 | 現在の固有感覚を参照して将来の関節状態を予測 |
| **future_wrist** | curr_wrist (1位) | **均一型** (CV≈0.36) | 手首カメラ全体から将来の手首視点を生成 |
| **future_primary** | curr_primary (1位) | **最均一** (CV≈0.29) | 三人称視点シーン全体から将来シーンを生成 |
| **future_secondary** | curr_secondary (1位) | 均一型 (CV≈0.31) | 右三人称視点全体から将来視点を生成 |
| **value** | proprio (1位) | 中程度集中 | 固有感覚から状態価値を推定 |

### 5.2 三つの発見

**発見 1: モダリティ対応型注意（Modality-Matched Attention）**  
各出力トークンは対応する入力トークンに最も強く注目する:
```
future_wrist    → curr_wrist    (同じカメラ視点)
future_primary  → curr_primary  (同じカメラ視点)
future_secondary→ curr_secondary(同じカメラ視点)
future_proprio  → proprio       (同じ変数型)
action          → proprio       (制御変数 → 固有感覚)
value           → proprio       (評価 → 固有感覚)
```
この構造は、**共有ラテント空間の中でも機能的役割が明確に分離**されていることを示す。

**発見 2: アクション生成は「固有感覚 + 局所視覚」戦略**  
- アクション (T=5) は proprio への注意が最大（Block 18 で 0.000965）
- 画像では curr_wrist への注意が最大かつ空間的に集中（CV=1.016、ピーク底辺）
- 「グリッパーが今どこにあるか」という局所的な視覚情報 + 関節角度から動作を決定
- 対照的に将来画像生成は curr_primary への均一注意（全景把握）

**発見 3: 注意パターンはデノイジングステップ不変**  
- Block 18 での k=0 vs k=4 の最大差が 0.0000378（約 0.004%）
- 「どこを見るか」はデノイジング開始前に決まり、5 ステップを通じて変化しない
- これは self-attention による情報ルーティングが **拡散過程の外側**（観測入力のみ）に依存していることを意味する

### 5.3 層深度の影響

| 段階 | ブロック | 特徴 |
|------|---------|------|
| 初期層 | Blk 0 | 全トークンへ一様（未分化）|
| 分化始動 | Blk 4 | モダリティ対応が徐々に現れる |
| **特異性ピーク** | **Blk 9〜22** | **モダリティ対応型注意が最も強い**（future_primary→curr_primary で 0.00170）|
| 最終層 | Blk 27 | blank (T=0) への注意が急増（action: 0.00123、future_wrist: 0.00152）|

最終層（Blk 27）で blank に注目が集まる現象は:
- blank トークンは「zero-input」として機能し、モデルの learned bias を表現
- 生成の最終段階で入力観測への依存を減らし、モデル内部の「デフォルト状態」を参照する可能性

## 6. 実験的発見と設計上の示唆

### 6.1 発見のまとめ表

| 検証項目 | 結果 |
|--------|------|
| action の最大注意入力 | proprio（固有感覚） |
| action の画像注意（空間的） | curr_wrist 底辺（グリッパー領域） |
| 将来画像生成の主な参照元 | 対応する現在画像（モダリティ対応） |
| 空間的注意の均一性 | 将来画像 > value > action（action が最も集中） |
| デノイジングステップ依存性 | ほぼゼロ（5 ステップで最大変化 < 0.004%） |
| 層深度の影響 | 中間層で特異性最大、最終層で blank に集中 |

### 6.2 モデル設計への示唆

1. **視野角の重要性**: action は curr_wrist に最も強く注目。  
   手首カメラはグリッパーとオブジェクトの位置関係を直接示すため、制御に最重要。

2. **固有感覚の汎用性**: proprio は action・value・future_proprio の全てで最上位。  
   関節状態は「今何をしているか」「何をするべきか」の両方に基本的な情報を提供。

3. **世界モデルの空間的一貫性**: 将来画像は現在画像全体を均等参照→シーン全体の文脈から整合した予測を生成。
