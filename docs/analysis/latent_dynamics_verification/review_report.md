**査読者の立場**：ML トップ国際会議（NeurIPS / ICML / ICLR / CoRL 級）Program Committee メンバー、
専門は表現学習・ロボット方策の解釈可能性・介入的因果検証。

## 0. 総合判定

| 項目 | 評価 |
|---|---|
| **現状の推奨判定** | **Reject**（Soundness 2/5, Contribution 3/5, Presentation 2/5, Confidence 4/5） |
| **改訂後のポテンシャル** | **Accept 圏（Borderline Accept 〜 Accept）**。否定的結果としての価値は高い |
| **致命的欠陥の数** | 設計 6件 / 手法 9件 / バグ疑い 5件 / 論理 6件 |
| **採択に最低限必要な追加実験** | 5件（§6.1 の MUST-1〜MUST-5） |

### 判定理由（3行要約）

1. **中心的な因果主張（言語なしでのアクション駆動）の否定的結果が、解釈不能である**。介入チャネルそのものが行動を制御しうることを示す **positive control（介入能力の上限）が一つも存在しない**ため、「不変量が操作できない」のか「この注入点では何も操作できない」のかを区別できない。
2. **最も新規性が高いと自称する肯定的知見（D空間でDMDシグナルが顕在化）が、交絡している**。「感覚運動結合」の効果と「遅延埋め込み」の効果が分離されておらず、v2 の3群比較でもこの交絡は解消していない。
3. **統計の中核部分に系統的な誤りがある**。完全分離時の p 値を効果量として扱い、p 値の比（「690倍」）を効果の強化として報告している。従属サンプル（重複窓）を独立として検定している。多重比較補正が一切ない。

### 一方で、明確に評価すべき点（査読者として先に明記する）

これは「悪い研究」ではない。以下は多くの投稿論文より優れている：

- **バグを隠さず全件記録する姿勢**（v1 §7、v2 §6）。特にバグ#2（非因果的リーク）を修正前後の数値変化（p=6.85e-7 → 0.023）とともに開示している点は、査読者として高く評価する。多くの論文はこれを黙って修正する。
- **循環性回避の原則の徹底**（成功エピソードのみで参照分布/KDEを学習、GroupKFold(group=episode)）。これは正しく、かつ多くの類似研究が犯す誤りを回避している。
- **T1（α=0 no-op）チェックの毎回実行**。介入実験の必須衛生条件であり、実施されている論文は少数派。
- **v2 §4.2.5 の3群比較設計**（サンプル効果と表現効果の分離）。着想は正しく、査読者が要求する前に自ら実施している。ただし §3 D-3 の通り不完全。
- **否定的結果を否定的結果として報告する規律**。「都合の良い部分だけを取り上げない」という節見出しを実際に守っている。

**この規律の高さゆえに、以下の指摘は「杜撰さ」ではなく「設計上の盲点」に対するものである。**

## 1. 検証目的に対する「必要十分性」の評価

design.md が要求する主張は、正確には次の2つに分解される：

- **(R) 表現の主張**：感覚と運動の結合動態を一次的対象として埋め込むと、分離表現では見えない不変構造が現れる。
- **(C) 因果の主張**：その不変量（ベクトル場）への動的介入により、言語なしでアクションが駆動される。

**現状の検証は (R) についても (C) についても必要十分ではない。** 以下、致命度順に列挙する。

### D-1【致命的】(R) の検証に「結合の効果」を単離するアームが存在しない

v1 §3.3 の中心的知見は次の比較である：

| 比較対象 | PnP の DMD 検定 |
|---|---|
| `X_p` 空間（PCA(10)、遅延埋め込み**なし**、行動ブロック**なし**） | p = 0.38〜0.59（非有意） |
| D 空間（τ=3 遅延埋め込み**あり**、行動ブロック**あり**、PCA(8)） | p = 0.0228（有意） |

**この2条件は最低3つの要因で異なる**：(i) 遅延埋め込みの有無、(ii) 行動ブロック（Δeef/Δgrip）の有無、(iii) 次元数と分散構造（10次元 vs 72→8次元圧縮）。
にもかかわらず、レポートは差分を全面的に (ii) に帰属させている（v1 §3.4「潜在表現単体では見えなかった力学的シグナルが、行動の物理的効果を結合することで顕在化した」）。

さらに悪いことに、**この交絡は v2 でも解消されていない**。v2 の3群比較は

- (1) collect_v2 × eef/grip代理指標
- (2) collect_actions × eef/grip代理指標
- (3) collect_actions × 行動チャンクPCA

であり、**すべてのアームが「遅延埋め込みあり＋何らかの行動ブロックあり」**である。「行動ブロックなし」のアームが一つもない。したがって v2 §5 の統合結論「感覚運動の結合を表現として埋め込むことに関する仮説は一貫して支持され強化された」は、**論理的に導出できない**。

**必要な追加アーム（MUST-1）**：同一サンプル（`collect_actions/`）上で、以下の4アームを構築し同一の DMD 検定を適用すること。

| アーム | c_t の構成 | 遅延埋め込み | 検定する要因 |
|---|---|---|---|
| A0 | `[Xp]` (10dim) | なし（＝現行の `X_p` 空間） | 基準 |
| A1 | `[Xp, V]` (20dim) | **あり**（τ=3, PCA(8)） | **遅延埋め込み単独の効果** |
| A2 | `[Xp, V, A_PCA_shuffled]` (25dim) | あり | **次元追加のみの効果（プラセボ）** |
| A3 | `[Xp, V, A_PCA]` (25dim) | あり | 結合の効果（＝現行(3)） |

`A_PCA_shuffled` は行動チャンクPCA特徴をエピソード間・時間方向にシャッフルし、周辺分布と分散スケールだけを保存したサロゲートとする。
**判定基準**：A1 で既に p≈0.02 が出るなら (R) の主張は崩壊する。A2 で改善するなら「次元を足せば DMD の見かけの分離は上がる」という測定アーチファクトである。**A3 > A2 ≈ A1 ≈ A0 が示せて初めて (R) は支持される。**

査読者の予測（明記しておく）：**A1 だけで大部分が説明される可能性が高い**。理由は §4 の B-3 に示す通り、遅延埋め込みは DMD の推定対象に shift 演算子構造を人工的に注入するためである。

### D-2【致命的】(C) の検証に positive control（介入能力の上限）が存在しない

C0〜C5 のすべてにおいて、「Blk-13 の action-token 出力に方向ベクトルを加算する」という介入チャネルが、**そもそも所望の行動を誘発しうるだけの帯域を持つのか**が一度も確認されていない。

- C1（ダミープロンプト）が success_rate = 0.00 で床に張り付いている。レポート自身が v1 §4.4 で床効果を認めている。
- しかし床効果を認めた上での正しい対処は「より細かい指標を見る」（v1 §5 が行ったこと）**ではなく**、「介入チャネルが機能することを示す上限実験を置く」ことである。

**必要な追加条件（MUST-2）：オラクル介入**

同じ注入点・同じ α スケジュールで、以下を注入する条件を追加せよ：

```
Δ_oracle = h_Blk13(o_t, e_real) − h_Blk13(o_t, e_dummy)
```

すなわち、同一観測・同一ノイズ・同一 seed のもとで実プロンプト条件とダミープロンプト条件の Blk-13 活性の差分（真の「言語が生んでいる差」）を、ダミープロンプト条件に注入する。

- **もし Δ_oracle 注入で success_rate が C0 水準（0.50）へ回復するなら**：注入チャネルは十分な帯域を持つ。したがって C2 の失敗は「動的フィールドが供給する情報の不足」に正しく帰属でき、**否定的結果が初めて解釈可能になる**。これは論文の主張を大幅に強化する。
- **もし回復しないなら**：Phase 3・5・6 のすべての否定的結果は「介入手法の失敗」ではなく「注入点の失敗」であり、**現在の結論はすべて撤回が必要**。

この実験は既存コードでほぼ実装可能（`FinalFeatCapture` を実/ダミー両プロンプトで走らせて差分を取るだけ）で、GPU 数時間で終わるはずである。**これがない限り、Phase 3・5・6 の否定的結果は査読を通らない。**

補助的に、**学習ベースの上限**（注入ベクトルを success_rate 最大化で直接最適化する、あるいは CMA-ES で探索する）も置ければ理想的。「最適化しても駆動できない」なら極めて強い否定的主張になる。

### D-3【重大】従属変数が床に張り付く設計を、3フェーズにわたって繰り返している

Phase 3・5・6 のすべてで主要従属変数が success_rate（二値、n=8）であり、対照条件が全部 0/8 である。0/8 の Clopper–Pearson 95% 上限は **0.369**（片側95%上限 0.312）であり、真の成功率が 15% でも 0/8 を観測する確率は 27.2%、25% でも 10.0% である。

**つまり本研究は「成功率 30% 未満の効果」を検出する能力を構造的に持たない。**
にもかかわらず、v1 §4.5・v2 §2.5・§3.5 はいずれも「**反証**」という語を用いている。これは overclaim であり、査読者は必ず指摘する。

**必要な設計変更（MUST-3）：床のない graded な従属変数を主指標に据える**

先行検証が既に使っていた `frac_closed_at_checkpoint` に加え、以下を推奨：

- 対象物体までの最小距離 `min_t ‖eef_t − p_object‖`
- 把持試行回数 / 接触イベント数（MuJoCo の contact から取得可能）
- 対象物体の変位量（タスク進行の連続代理）
- 到達フェーズ完了率（phase ラベルが既にある）

これらは 0 に張り付かないため、C2 vs C3 vs C4 の比較に検出力が生じる。**現在の「success_rate が全部 0 なので区別できない」という状況は、指標選択で回避できたものである。**

### D-4【重大】「言語なし」条件が「言語なし」になっていない

C1〜C5 の「ダミープロンプト」は `"The weather today is sunny."` の T5 埋め込み1本である。これは以下の理由で言語アブレーションとして不適切：

1. **OOD 条件付け**である。モデルはロボットタスク記述以外で条件付けられた経験を持たない。C1 の完全崩壊は「言語情報の欠如」ではなく「分布外条件付けによる崩壊」で説明できてしまう。両者を区別する設計になっていない。
2. **単一文のみ**。「ダミープロンプト」効果がこの1文に固有でないことが確認されていない。
3. v2 §2.4 の中心的考察「言語が担っているのは選択情報ではなくタスクの発火条件そのもの」は、この交絡を除かない限り**主張できない**。

**必要な追加条件（MUST-4）：言語アブレーションの階層化**

| 条件 | 実装 | 検定する仮説 |
|---|---|---|
| L0 | 実プロンプト | 基準 |
| L1 | 零ベクトル埋め込み（+ attention mask 全マスク） | 真の「条件付けなし」 |
| L2 | 全タスク記述埋め込みの平均 | 「言語はあるがタスク特異性なし」 |
| L3 | **他タスク**の実プロンプト（例: PnP に "close the drawer"） | 言語の**特異性**（最も重要） |
| L4 | 無関係文（現行のダミー、複数文で） | OOD 条件付け |

L1 と L4 の差が大きければ、現在の「ダミープロンプト」結果は OOD アーチファクトを含む。
L3（他タスク指示）は特に重要で、「言語がタスク**選択**を担う」のか「言語が**発火**を担う」のかを直接分離できる。v2 §2.4 の考察はこの条件なしには論理的に成立しない。

### D-5【重大】感覚運動随伴性の検証（C5）が、仮説を検定していない

v1 が「本検証で唯一かつ最も頑健な肯定的知見」と位置づける結果（§5.4、経路長比 4.20倍、p=7.8e-5）について。

**C5 は「観測を call 0 に固定」する条件である。この条件下では、方策への入力がほぼ定常になるため、出力もほぼ定常になる。これは観測条件付き方策であれば何であれ成立する自明な性質である。**

design.md が要求しているのは「観測を変化させた際、出力アクションが Reactive な一定出力にならず、**不変量を維持したまま柔軟に調整される**か」である。C5 が示したのは「入力を止めると出力が止まる」であって、「不変量を維持したまま調整される」ではない。**純粋に reactive な刺激-反応写像でも、C2 vs C5 の結果は完全に同じになる。** したがってこの結果は design.md が否定したい仮説（reactive 表象主義）を反証していない。

しかも v2 §2.3 で CloseDrawer では経路長比が 0.903（方向逆転、p=0.052）となり、指標の頑健性自体が崩れている。v2 §2.4 はこれを外れ値の問題として扱っているが、**そもそも指標が仮説を検定していない**ことの方が重大である。

**必要な設計変更（MUST-5）：随伴性の階層的統制**

| 条件 | 観測の操作 | 検定内容 |
|---|---|---|
| S0 | 通常 | 基準 |
| S1 | call 0 に固定（現行 C5） | 入力定常 → 出力定常（自明） |
| S2 | **他エピソードの観測ストリームを再生** | 非定常だが自エピソードと無相関 |
| S3 | **時間順シャッフルした自エピソードの観測** | 統計は保存、時間構造のみ破壊 |
| S4 | **エピソード途中で対象物を移動**（介入的摂動） | **真の随伴性テスト** |

S4 が核心である。「対象物を動かしたとき、行動が**その物体を追って**調整されるか」を測れば、単なる変動ではなく「不変量を維持した柔軟な調整」を検定できる。measure は「摂動後の eef 方向と新物体位置方向のコサイン類似度」。
S2/S3 が S0 と同程度に「豊かな変動」を示すなら、現在の肯定的知見は「入力が変われば出力が変わる」以上の内容を持たないことが確定する。

### D-6【中】ベースラインが一つも存在しない

トップ会議の投稿として、「言語なしでアクションを駆動する」という問題設定に対する既存アプローチとの比較が皆無である。最低限：

- **goal-image conditioning**（言語の代わりにゴール画像で条件付け）
- **retrieval-based action replay**（最近傍成功エピソードの行動チャンクをそのまま再生）
- **activation steering 文献の標準手法**（difference-in-means steering, CAA, ITI 等）との比較

特に retrieval baseline は重要で、「kNN フローライブラリで潜在に介入する」より「kNN で行動そのものを再生する」方が強いなら、提案手法の存在意義が問われる。これは実装 30 行で可能。

## 2. 【致命的】アーキテクチャ的前提の誤り

これは §1 とは独立の、より深い問題である。

### M-1 拡散方策には「書き換えるべき状態の速度」が存在しない

design.md フェーズ3の定式化：

```
Z_{t+1} = Z_t + α · Proj_manifold(V_target_dynamics)
```

この式は **Z が自律的な力学系の状態変数である**ことを前提としている。しかし Cosmos Policy において Blk-13 の action-token 特徴は

```
Z_t = f(o_t, e_text, ε_k, σ_k)
```

として**各 call で観測とノイズから新規に計算される readout** であり、call 間で持ち越される再帰状態ではない。したがって「速度ベクトルを書き換える」という操作は原理的に不可能で、実際に実装されているのは「call ごとに方向を再計算する静的加算」である。

**帰結**：C2（動的フィールド）と C3（静的 v_steer）の違いは、加算ベクトルが call ごとに変わるか否かだけである。もし加算方向が実際にはほとんど変化していなければ、**C2 と C3 の比較は同語反復であり、v1 §4.5 の「動的介入は静的介入と区別できない」という結論は、実験結果ではなく実装の帰結**ということになる。

**必須の診断（即実施可能・GPU不要、既存 JSON から計算できる）**：

```python
# 各エピソードについて
cos_consecutive = [cos(v_t, v_{t+1}) for t in calls]
cos_to_mean     = [cos(v_t, mean_t(v_t)) for t in calls]
participation_ratio = (sum(v**2)**2) / sum(v**4)   # 方向の集中度
```

- `mean(cos_consecutive) > 0.95` なら、C2 は事実上 C3 である。この場合、論文は「動的介入を検定した」と主張できない。
- 併せて、C2 と C3 の加算ベクトル間の平均コサイン類似度も報告すること。これが高ければ両条件はそもそも別条件ではない。

**論文としての正しい書き方**：「拡散方策は再帰状態を持たないため、design.md の定式化を文字通り実装することはできない。本研究は最も近い近似として per-call 再計算型の活性加算を実装した」と明記し、その限界を主張の範囲に反映させること。現状は定式化と実装の乖離が読者に開示されていない。

### M-2 フローを推定した空間と、介入を注入する空間が異なる

- v1 §4.2.5(i)：状態推定は「このcallの Blk-13 特徴（**最終デノイジングステップ**）」を捕捉して行う。
- v1 §4.2.4：注入は「早期 k=(0,1)」の Blk-13 出力に対して行う。

σ スケジュールは 80.0 → 42.3 → 21.0 → 9.6 → 4.0 であり、**k=0 と k=4 では σ が 20倍違う**。活性の分布・スケール・意味構造が同一である保証はない。`X_p` の PCA 基底・`scale_ambient` はすべて最終ステップ特徴から推定されているのに、それを早期ステップの特徴に加算している。

**要求する検証**：
1. k=0,1,4 それぞれの Blk-13 特徴の norm 分布・共分散を比較。
2. 最終ステップで学習した PCA(10) 基底で早期ステップ特徴を射影したときの説明分散比。これが低ければ、介入方向は早期ステップにおいて意味を持たない。
3. k_range の網羅的スイープ（(0,1), (2,3), (3,4), (0,4) 全部）。先行検証 §10 が「後期スケジュール・大振幅でタスクが破壊された」ことを報告しているなら、**後期こそが有効なチャネル**であり、早期のみを選んだ現行設計は最も効きにくいチャネルを選んでいる可能性が高い。否定的結果の信頼性に直結する。

### M-3 ベクトル場の「大きさ」を捨てている

v1 §4.2.4：「この `Δ X_raw` を**単位ベクトルに正規化し**、α 倍して加算する」。

フェーズ2で推定したエネルギー勾配 `∇log p` とフロー `v_target` の**大きさ**は、ベクトル場の本質的な情報（谷の深さ、引き込みの強さ）である。これを正規化で捨てると、残るのは方向のみになり、「エネルギー場の谷を深くする」という design.md の仮説の実装として不完全である。α も定数。

**修正**：`α_t ∝ ‖v_field(D_t)‖` とする適応的スケーリング条件を追加し、定数 α 条件と比較すること。これは design.md の仮説により忠実な実装であり、追加コストはほぼゼロ。

### M-4 オンライン状態推定器の分布シフトが未検証

オフラインの `X_p` はエピソード平均による scene 残差化、オンラインは累積平均（running mean）による近似（v1 §4.2.1）。**両者が同じ分布になることは一度も確認されていない。**

さらに、フローライブラリは**実プロンプトの成功エピソード**のみから構築されているのに、クエリは**ダミープロンプトの崩壊した軌跡**から発せられる。これは典型的な外挿である。

**必須の診断**：
- 各条件・各 call について kNN 距離 `d_k(D_t)` を記録し、オフラインライブラリ内の最近傍距離分布と比較（分位点で報告）。
- C0（実プロンプト）と C1〜C5 で kNN 距離分布を比較。C2 の大多数のクエリがライブラリの外側にあるなら、`v_target` は**外挿されたゴミ**であり、否定的結果は「動的介入の失敗」ではなく「クエリ点の OOD 性」で説明される。

これは JSON に保存済みの `d_traj` から即計算できるはずである。

### M-5 Takens の定理の誤用

Takens の埋め込み定理が保証するのは、**決定論的・自律的**な力学系を**スカラー観測**を通じて観測した場合の位相空間再構成である。本設定は
(i) 環境入力に駆動される非自律系、(ii) call ごとの拡散サンプリングによる確率系、(iii) 観測は既に高次元、
のいずれにおいても前提を満たさない。

現状のように定理名を引用すると、査読者は「理論的裏付けを装った単なる窓連結」と判断する。**「遅延窓特徴連結」と記述し、Takens への言及は related work での動機付けに留めること。** 主張の正当性は下がらず、査読耐性だけが上がる。

### M-6 相関次元推定に Theiler window がない

v1 §2.3 の「D空間の内在次元は相関次元で 1.4〜2.7」という主張は、本研究の「低次元性」という基盤的知見を支えている。しかし軌跡データに対する Grassberger–Procaccia 相関次元は、**時間的に近接したペアを除外する Theiler window を設けないと系統的に過小推定される**。連続する call の点は自明に近接しているため、相関積分が小さい ε で人工的に膨らむ。

しかも本研究では τ=3 の遅延埋め込みにより **連続する D_t が成分を共有している**ため、この過小推定はさらに増幅される。

**修正**：Theiler window（最低でも τ+窓幅、推奨は自己相関の第一零点）を設けて再推定し、window 幅に対する感度を報告すること。「相関次元 1.4」という値は、この補正で有意に変わる可能性が高い。

### M-7 KDE によるエネルギー場は密度ではなく「データまでの距離」である

8次元・N≈500〜1000、Scott 則帯域幅（h = N^{-1/(d+4)} ≈ 0.56）。この設定で推定される KDE は密度推定として意味を持たない（curse of dimensionality）。実質的には**平滑化された最近傍距離**である。さらにサンプルは軌跡上で強く自己相関しているため、「密度」は滞在時間に支配される。

レポート自身が v1 §3.4 で「§5.6 の逸脱量検定と本質的に同じ情報を測っている可能性が高い」と正しく懸念している。**その懸念は正しい。** 正しい対処は：

- 自明なベースライン（成功軌跡への最近傍距離、1-NN 分類器）と AUC で比較し、KDE エネルギーが上回るかを示す。上回らないなら「エネルギー場」という概念装置は本研究では正当化されない。
- エピソード単位のラベル置換検定で帰無分布を作る。

### M-8 DSM-MLP が検証にも本番にも使われていない

v1 §3.2.2 で DSM を実装し、2次元2成分ガウス混合という**自明に易しい**問題で検証（cos 0.93/0.96）した後、実データには使わず解析的 KDE を使用している。

- 2D ガウス混合での検証は 8次元多様体データへの妥当性を何ら保証しない。
- design.md の「score matching の技術を流用せよ」という要求は、**実質的に満たされていない**。

**選択肢は2つ**：(a) DSM を実際に本番のベクトル場推定に使い、KDE と比較する（design.md への忠実性が上がる）、(b) DSM を論文から削除し「KDE スコアを用いた」と正直に書く。現状の「実装したが使わなかった」記述は、査読者に「要求を形式的に満たしただけ」という印象を与える。

### M-9 DMD の設定が推定限界に近く、帰無分布がない

窓幅 8（＝7 スナップショットペア）で 8次元（rank≤4 打ち切り後4次元）の線形写像 A を最小二乗推定している。4×4 を 7 ペアから推定するのは過適合領域であり、`|λ_max|` は上方バイアスを持つ。

さらに致命的なのは、**D_t が τ=3 の遅延窓であるため、連続する D_t は成分を共有する**。この場合、線形写像 A の一部は系の力学ではなく**遅延埋め込みが持つシフト演算子構造**を推定している。シフト演算子の固有値は単位円上にあるため、`|λ|≈1` 近傍への系統的バイアスが生じる。そして (2)→(3) の変更は窓の中身を変えるため、**この人工構造の量を変えてしまう**。

**必須の対処**：
1. サロゲート帰無分布を作る（IAAFT または episode ラベル置換）。同じ窓幅・同じ rank 打ち切りでサロゲート軌跡に windowed DMD を適用し、`max|λ|` の帰無分布を得る。閾値 1.0 の代わりにこの帰無分布の分位点を使う。
2. 窓幅（6, 8, 12, 16）と rank 上限（2, 4, 6）への感度分析。「§5.7 からの継承であり再チューニングしていない」（v1 §3.6-5）は、空間が変わった以上、通用しない。
3. **上記 D-1 の A1 アーム**（行動ブロックなしの遅延埋め込み）で人工構造の寄与を単離する。

## 3. 【要調査】実装バグを疑うべき数値

「結果に実装バグを疑う値が出ているか」という観点への回答。**出ている。5件。** 優先度順。

### B-1【最優先】主要 p 値の多くが群サイズだけの関数になっている

完全分離時、Mann–Whitney U は U = n₁n₂ に張り付き、p は (n₁, n₂) のみの関数になる。連続性補正つき漸近正規近似で再計算した値と報告値の照合：

| n₁/n₂ | 完全分離時の理論 p（再計算） | レポート報告値 | 該当箇所 |
|---|---|---|---|
| 18/22 | 3.952×10⁻⁸ | **3.91×10⁻⁸** | v1 §2.3, §3.3（PnP 逸脱・エネルギー） |
| 19/21 | 3.529×10⁻⁸ | **3.50×10⁻⁸** | v2 §4.3（PnP 逸脱 (2)(3) 両方） |
| 15/25 | 8.743×10⁻⁸ | **8.63×10⁻⁸** | v1 §2.3, §3.3（TurnOnStove） |
| 16/24 | 6.220×10⁻⁸ | **6.12×10⁻⁸** | v2 §4.3（TurnOnStove (2)(3) 両方） |

**4件すべて一致する。** つまりこれらの p 値は**効果量の情報を一切含んでいない**。v1 §7 バグ#3 でこの現象（天井効果）を自ら正しく特定しているにもかかわらず、**その後の全表で同じ p を主要指標として掲示し続けている**のは重大な報告上の欠陥である。

**要求**：これらの p を表から削除するか、「完全分離（AUC=1.0）」という記載に置き換え、効果量として **AUC（= U/n₁n₂）とその bootstrap CI**、および正規化マージンではなく**エピソード単位ブートストラップによる分離度の CI** を報告すること。

なお現行の「正規化逸脱マージン」`(min(fail) − max(succ))/std(succ)` は2つの順序統計量の関数であり分散が極めて大きい。v2 §4.3 で TurnOnStove のマージンが 5.82 → −2.42 と符号反転しているのは、この指標の不安定性の表れであり、指標として使えない。

### B-2【最優先】オフラインとオンラインで「多様体逸脱度」の挙動が矛盾している

| 文脈 | 数値 |
|---|---|
| v1 §2.3（オフライン、PnP、D空間） | 成功/失敗が**完全分離**、fail/succ 逸脱比 **2.34** |
| v1 §5.3（オンライン、PnP、`xp_traj`） | C0=4.821, C1=4.961, C2=4.886, C3=4.974, C4=4.935 |

**オンラインでは全条件が 3% 以内に収まっている。** C0 は success_rate=0.50（成功エピソードを4本含む）、C1 は 0.00（全失敗）である。オフラインで完全分離する指標が、オンラインで成功50%群と失敗100%群を**まったく区別できない**のは、内部矛盾である。

考えられる原因：
1. **featurization の train/test 不一致**：参照分布はエピソード平均残差化された `X_p` で学習、適用対象は running mean 残差化された `xp_traj`。同一のスケーラ・PCA が適用されているか要確認。
2. **進行度定義の破綻**：`episode_progress = t/T` で、失敗ロールアウトは全て T=500（上限）。成功エピソードは T≈220。同じ「進行度 0.5」がまったく違う状態を指す。
3. **標準化の適用漏れ**：`ambient_scaler` / `c_scaler` の適用順序がオフライン経路とオンライン経路で異なる。

**要求する診断（GPU不要）**：
- C0 の 8 エピソードを成功4/失敗4に分割し、逸脱度が分離するかを検定。**分離しなければ実装バグが確定的**。
- C0 ロールアウトで捕捉した生特徴に**オフラインのパイプラインをそのまま再適用**し、`xp_traj` と数値一致するかを assert。
- オンライン `X_p` とオフライン `X_p` の各次元の平均・分散を比較。

**加えて**：C5（観測固定、ほぼ静止）の逸脱度が全条件中**最小**（3.406）である。「動かないほど多様体逸脱が小さい」なら、この指標は多様体からの逸脱ではなく**移動量**を測っている。DTW/Fréchet でも同じ現象が起きており（v1 §5.4 で自ら指摘）、**2つの独立な指標が同じ縮退を示している**ことは、指標設計の問題というより実装の問題を疑わせる。

### B-3【高】注入ベクトルの成分集中度が異常

v1 §4.2.4 は `Δ X_raw` を**単位ベクトルに正規化して α=40 倍**する。したがって注入ベクトルの L2 ノルムは 40。
v1 §4.3 は「hook の実効 delta 最大値は 26.1〜27.0」と報告している。

もしこの 26〜27 が delta の**最大成分値**なら、単一座標が全エネルギーの (26/40)² ≈ **42%** を占めていることになる。2048 次元空間で一様な単位ベクトルの最大成分は ~0.02（×40 で 0.9）であるから、これは **30 倍近い異常な集中**である。

**疑うべき機序**：`Δ X_raw = (v_field · components_prog_pca) ⊙ scale_ambient` において、Transformer 活性に典型的に存在する massive activation / outlier feature 次元の `scale_ambient` が突出していると、要素積の時点で方向がその1次元に collapse する。この場合、「動的フィールド steering」は実質的に**単一の外れ値チャネルへの注入**であり、C2・C3・C4 が区別できないことの直接的な説明になる。

**要求する診断（既存 artifact から即計算可能）**：
- `Δ X_raw` の participation ratio、top-1/top-5 成分のエネルギー占有率。
- `scale_ambient` の次元別分布（最大値/中央値の比）。
- 対照として、実プロンプトとダミープロンプトの Blk-13 特徴差分ベクトルの同じ統計。両者の集中度が桁違いなら、注入方向は「言語が作る方向」と全く別物である。
- **修正案**：正規化を raw 空間ではなく標準化空間で行う（`Δ X_std` を単位化してから `scale_ambient` を掛ける）、あるいは per-dimension clipping を導入し、感度分析すること。

**併せて単位の不整合**：v1 §4.2.7 は α=40 を「典型特徴 norm 196.2 に対する比 20.4%」と述べ、§4.3 は delta **最大値** 26 を「ambient 比 13.3%」と述べている。前者はノルム比、後者は最大成分/ノルムであり、**分母と分子の定義が混在している**。先行検証の「α=8〜16 の比 85〜171%」も同じ混在の可能性がある。α 較正の根拠そのものが揺らぐため、単一の規約（‖Δh‖ / ‖h‖）に統一して全数値を再掲すること。

### B-4【中】v1 §7 バグ#4 の未修正部分が先行検証の α 較正に波及している可能性

`SteeringHook.last_delta_max` が常に 0 を報告していたバグが `steering_intervention.py` 側に残っている、と v1 §7-4 は述べる。「当該レポートの結論は実測の行動指標に基づくため影響しない」という判断は**主張であって検証ではない**。

問題は、先行検証の α 較正（「典型特徴 norm に対する比」）がこの診断値に依存していた場合、**本検証の α=40 の選定根拠そのものが不正確な数値の上に立つ**ことである。B-3 の単位混在と合わせて、α の意味を一から再構成すべきである。

**要求**：先行検証の該当スクリプトで `max_hook_delta_observed` が実際に 0 を返していたかを確認し、返していたなら先行検証の α 較正テーブルを再計算して差し替えること（コード修正は不要、再測定のみ）。

### B-5【中】DMD の `max|λ|` が「窓数」と交絡している

`max|λ|` は**エピソード内の全窓にわたる最大値**である。極値統計として、窓数が多いほど最大値は系統的に大きくなる。

- 成功エピソード：n_steps ≈ 217〜248 → call 数 ≈ 14〜16 → 窓数 ≈ 7〜9
- 失敗エピソード：n_steps = 500（上限） → call 数 ≈ 31 → 窓数 ≈ 24

**失敗エピソードは成功エピソードの約 3 倍の窓を持つ。** したがって「失敗の max|λ| が大きい」「失敗の方が |λ|>1 到達率が高い」は、**力学的不安定性を一切仮定せずとも極値統計だけで生じる**。とりわけ「|λ|>1 に一度でも到達したか」という Fisher 検定は、定義上「試行回数が多いほど到達しやすい」統計量である。

これは v1 §3.3 / §3.5 と v2 §4.3 / §4.5 の**中心的な肯定的知見を丸ごと無効化しうる**交絡である。

**要求する対処**：
1. 群ごとの窓数を必ず表に併記する（現状どこにも書かれていない）。
2. `max|λ|` を **窓数マッチング**（成功エピソードの窓数に合わせて失敗エピソードから連続窓をサブサンプル、多数回反復して分布を得る）で再計算。
3. または窓数非依存の統計量（`median|λ|`、`|λ|>threshold` の**割合**、単位窓あたりの超過率）を主指標に変更。
4. さらに、`|λ|` を進行度でマッチングして比較（同じ進行度帯の窓同士を比べる）。

**査読者の予測**：窓数マッチング後、PnP の p=0.0228 は非有意になる可能性が相当高い。これが本研究の最重要の再解析である。

## 4. 【論理】考察・所感の妥当性

「考察は論理的に行われているか」への回答。**6箇所で論理が破綻している。**

### L-1 v2 §4.3・§4.4：p 値一致の原因を誤診断し、その上に考察を積んでいる

> 「(2)(3) で p 値が一致したのは、各 episode の max|λ| の episode 間**順位付けが両空間で偶然完全に一致した**ため」（v2 §4.3）

**誤りである。** B-1 で示した通り、TurnOnStove (2)(3) の p=6.12e-8 は n=16/24 における**完全分離時の天井値**（理論値 6.220e-8）である。Mann–Whitney U は「成功群のどの点も失敗群のどの点より小さい」ときに U=n₁n₂ に張り付き、**群内の順位がどうであろうと同じ値になる**。したがって「順位付けが一致した」という推論は成立せず、データは群内の任意の順序と両立する。

そして v2 §4.4 はこの誤診断の上に：

> 「TurnOnStove では『どの episode が力学的に不安定か』という順位付けそのものがロバスト」
> 「Xp・V だけで安定性のほぼ全てが決まっており、行動の付加情報が順位を変えないほど支配的」

という考察を展開している。**前提が偽なので結論も導出されない。** しかも v1 §7 バグ#3 で全く同じ天井効果を正しく診断していたにもかかわらず、v2 §6 では「同じ轍を踏まないよう最初から順位依存性を疑って調査した」と述べている。**同じ轍を踏んでいる。**

**修正**：該当箇所を削除し、「両表現とも完全分離のため Mann–Whitney では区別できない。効果量比較には AUC の飽和を回避する別指標（例：成功群と失敗群の分布間の Wasserstein 距離、あるいは cross-validated 分類器の margin 分布）が必要」と書き換える。

なお、**皮肉なことに v2 §4.4 の結論（「D空間は Xp・V に支配されている」）自体は正しい可能性が高い**——ただし根拠は p 値一致ではなく、c_t の 25 次元中 20 次元を Xp・V が占めるという構成上の事実と、TurnOnStove の逸脱検定 p が (2)(3) で 1.87e-6 と**完全一致**している（こちらは天井値ではないので真に順位が同一）という事実である。正しい根拠で書き直せば、この考察は残せる。

### L-2 v2 §4.4・§5：p 値の比を効果の大きさとして扱っている

> 「(2)→(3) の比較でも**約 690 倍 p 値が縮小**し、真に生成行動を用いた表現がこの力学的シグナルを強めることが確認された」

p 値は効果量ではない。比を取ることに統計的意味はない。しかも「有意 vs 非有意」あるいは「p の大小」の差自体が有意であることは**別途検定しなければならない**（Gelman & Stern の古典的指摘）。

報告 p から AUC を復元すると、実際の効果量は以下の通りである（連続性補正つき漸近正規近似の逆算）：

| アーム | 報告 p | **復元 AUC** |
|---|---|---|
| (1) collect_v2 × eef/grip | 0.0228 | **0.687** |
| (2) collect_actions × eef/grip | 0.0092 | **0.719** |
| (3) collect_actions × 行動チャンクPCA | 1.33×10⁻⁵ | **0.890** |

「690 倍」の実態は **AUC 0.719 → 0.890、差 0.17** である。n≈19/21 における AUC の標準誤差はおおむね ±0.08〜0.09 なので、この差は「見込みはあるが、単独では確定的でない」水準にすぎない。

**要求**：
- 全表を AUC（または rank-biserial correlation / Cliff's δ）+ bootstrap 95% CI に置き換える。
- (2) と (3) は**同一エピソード**なので、**エピソード単位の paired bootstrap で ΔAUC の CI を出す**こと。これが本来必要な検定であり、実施すれば主張は正当に強化できる（現状より説得力が上がる可能性が高い）。
- 「690 倍」という表現は論文から完全に削除する。査読者はこの一文だけで soundness を疑う。

### L-3 v1 §5.4 / v2 §5：反証と支持の非対称な扱い

同じ研究の中で：

- **肯定的知見**（DMD シグナル、感覚随伴性）→ 単一タスク・単一指標・n=8 でも「新規性の高い知見」「最も頑健な肯定的知見」と強く主張。
- **否定的知見**（steering 無効）→ 同じ n=8 で「反証」と断定。

さらに、多重比較が一切考慮されていない。両レポートを通じて Mann–Whitney/Fisher/Spearman を**ゆうに 50 回以上**実施している。族全体で FWER を制御すれば、p=0.0228（v1 の最重要肯定的知見）も p=0.0130 も p=0.0448 も**すべて有意水準を割る**。

**要求**：
- 主要仮説（事前に決めた少数）と探索的解析を明示的に分離する。
- 探索的部分には Benjamini–Hochberg を適用し、q 値を併記。
- 「反証」→「テストした範囲で効果を検出できなかった（検出可能な最小効果量は success rate 0.31）」に書き換える。

### L-4 v1 §5.4：C5 の DTW が小さい理由を正しく特定しながら、同じ論理を他の指標に適用していない

v1 §5.4 は C5 の DTW/Fréchet が小さいことを「動かないことのアーチファクト」と正しく指摘した。**優れた自己批判である。** しかし全く同じ論理が、同じ表の**多様体逸脱度**（C5=3.406 で最小）にも適用されるべきなのに、そこには適用されていない。そして v1 §5.5 の結論は多様体逸脱度を有効な指標として扱っている。

さらに、この「動かないほど良いスコアが出る」性質は C5 に限らず C1〜C4 の相互比較にも影響する（経路長 2.49〜2.54 で近いとはいえ）。**移動量を共変量として統制した解析**（経路長で回帰残差化、または経路長マッチングしたサブサンプル比較）が必要。

### L-5 v2 §2.4：CloseDrawer C5 の 1/8 成功に対する説明が事後的で検証されていない

> 「引き出しへ向かって押すに近い一定の運動を 500 ステップ持続すれば、機械的に引き出しが閉まる偶発的成功があり得る」

もっともらしいが、**検証可能なのに検証していない**。C5 の当該エピソードの eef 軌跡と引き出しの joint 値の時系列を見れば 5 分で判定できる。加えて、この仮説が正しいなら「**ランダムな一定行動でも CloseDrawer は時々成功する**」という強い予測が導かれる。

**要求**：ランダム定行動ベースライン（ゼロ行動、ランダム定ベクトル行動）を n=20 で走らせ、CloseDrawer の chance-level success rate を測定すること。これは全タスクの success_rate 解釈の基準線としても必要であり、**現状 chance level が一つも測られていない**のは設計上の欠落でもある（§1 D-6 と関連）。

### L-6 現象学的主張と統計的結果の対応づけが過剰

v1 §6：

> 「設計書が拠って立つ現象学的主張（行為は感覚運動の結合動態の中で立ち現れる、observation からの reactive な出力ではない）は、目的達成の成否とは独立に、この一点においては支持された」

D-5 で述べた通り、C2 vs C5 の結果は **reactive な刺激-反応写像でも同一**である。したがってこの結果は「reactive ではない」ことの証拠になり得ない。**支持されたと書かれている命題が、実験の論理構造上、支持されえない命題である。**

より一般に、両レポートは統計的検定の結果を哲学的命題の真偽判定に直結させる書き方をしている（「表象主義の破棄」「メルロ=ポンティ的運動的志向性の検定」等）。トップ会議では、これは主張の過剰一般化として減点対象になる。

**推奨する書き分け**：
- Introduction / Discussion では哲学的動機を明示的に「動機付け（motivation）」として述べる。
- 実験節では、その動機から導かれた**操作的で反証可能な仮説**（H1: 結合表現は分離表現より力学的分離の AUC が高い、H2: フロー介入は静的介入より success rate が高い、…）のみを検定対象として述べる。
- 結論では H1/H2 の採否のみを述べ、哲学的命題の採否は述べない。

**これは形式的な作法ではなく、実際に本研究の説得力を上げる。** 現状は「壮大な主張 + 弱い証拠」に見えるが、書き分ければ「明確な仮説 + 誠実な否定的結果」という、査読者が高く評価する形になる。

## 7. 軽微な指摘

1. v1 §4.3「C0 の success_rate=0.50 が先行検証と**完全一致**」— n=8 の 4/8 同士の一致であり、95% CI は [0.16, 0.84]。サニティチェックとしては弱い。「矛盾しない」程度の表現に。
2. v2 §4.3「8ファイル中6ファイルが成功率レベルで一致」— n=20 なので ±5pt = 1 エピソード。有意な一致とは言えない。
3. v1 §2.3 の `n90_variance=8` を「測定上のアーチファクト」と自ら明記しているのは良いが、**それなら表から削除すべき**。誤読を招く数値は載せない。
4. DSM の合成検証（2D ガウス混合）を「合格基準 0.8」としているが、この基準の根拠がない。事前に基準を置く姿勢は良いので、基準の妥当性の議論を一文加えるだけで良い。
5. v1 §3.4 の Spearman ρ = −0.121 (p=0.0013, n=697) — **697 個の窓は独立ではない**（同一エピソード内、かつ窓が重複）。エピソード単位のクラスタを考慮した検定（block permutation / mixed model）に置き換えること。現状の p は大幅に anti-conservative。この誤りは「符号が直感に反する」という考察の前提を揺るがす。
6. `c_t` の先頭 padding（最古の c の繰り返し）は、Phase 6 の `fadeout_calls=5` とちょうど重なる領域である。**介入を開始する call 5 は、状態推定器が最も信頼できない時点**である。この相互作用は §3.6 の限界に記載されていない。
7. TurnOnStove が design/report で「ノブを回す」（v2 §4.4）と記述されているが、タスク名は stove の点火であり、記述の正確性を確認されたい。
8. 図表の言語・記法が日英混在。投稿版では統一を。

## 8. 査読者としての最終コメント

本研究の**科学的規律は投稿論文の平均を明確に上回っている**。バグの全件開示、循環性回避、no-op チェック、否定的結果の正直な報告、そして v2 §4.2.5 の交絡分離設計は、いずれも訓練された研究者の仕事である。**Reject 判定は、研究者の姿勢ではなく、主張と証拠の間のギャップに対するものである。**

ギャップの本質は一つに集約できる：

> **「読み出し（read）」の主張は交絡した比較の上に立っており、「書き込み（write）」の主張は上限が測られていない。**

前者は MUST-1（4アーム・アブレーション）で、後者は MUST-2（オラクル介入）で解決する。この 2 実験は既存コードの延長で実施可能であり、合計で数日の作業と推定される。**この 2 つが揃えば、本研究は「拡散方策における感覚運動構造の read/write 非対称性」という明確で新規な主張を持つ論文になり、否定的結果を主題とする論文としてトップ会議で戦える。**

逆に、MUST-1 で A1（行動ブロックなしの遅延埋め込み）が既に p≈0.02 を出した場合、あるいは MUST-2 でオラクル介入も失敗した場合、本研究の主張は根本的な書き換えを要する。**その可能性は低くないと査読者は考えており、だからこそこの 2 実験を最優先すべきである。** 早期に実施すれば、誤った方向への追加投資（NICE TO HAVE 項目群）を回避できる。
