# Cosmos Policy 介入検証・再設計プラン
## — 5本の先行研究に基づく「効く介入」への到達経路

---

## 0. 前提の訂正：Cosmos-Policy は介入可能である

前回までの検証は「動的フィールドsteeringが効かない」→「潜在空間の操作でアクションは駆動できないのでは」という方向に傾いていた。**この推論は先行研究と矛盾する。**

Hong et al. (arXiv:2607.14943, WA-LQR) は **Cosmos-Policy 2B を主対象**とし、
LIBERO-10 上で以下を報告している。

- 活性空間の低次元線形分離性から **steerability を事前予測**でき、Cosmos-Policy と DiT4DiT は「強く steerable」、LingBot-VA は「弱い」と予測された。
- 実際の介入実験がこの予測と一致した。Cosmos-Policy では WA-LQR がカメラ・グリッパー初期位置・視覚ノイズの各摂動に対し、無介入・prompt steering・複数の open-loop steering baseline を上回った。

つまり **「Cosmos-Policy の活性空間は行動レベルの因果を持つ」ことは既に外部で確認済み**である。
したがって今回の否定的結果は、モデルの性質ではなく**介入設計の問題**として扱うべきである。

以下、5本から得られる 9 個の具体的な設計上の欠陥と、それを潰す検証プログラムを示す。

## 2. 失敗の再診断（9項目）

### 2.1 【致命的】力学系の時間軸を取り違えている

design.md の `Z_{t+1} = Z_t + α·Proj(V_target)` は、Z を env の call をまたいで持ち越される状態変数と仮定している。しかし拡散方策では Z は毎 call `f(o_t, e_text, ε_k, σ_k)` として再計算される readout であり、書き換えるべき速度が存在しない。

**WA-LQR の解法**：時間軸を **DiT のブロック index ℓ** に取る。

```
x_{l+1,t} = φ^(l)(x_{l,t}, t, h) + u_{l,t}        （制御入力 u を持つ実在の力学系）
δz_{l+1,t,τ} ≈ Ã_{l,t} δz_{l,t,τ} + B̃_{l,t} δu_{l,t,τ}
    Ã_{l,t} = P_{l+1,t} A_{l,t} P_{l,t}^T,   B̃_{l,t} = P_{l+1,t} B_{l,t}
    A_{l,t} = ∂f_{l,t}/∂x,  B_{l,t} = ∂f_{l,t}/∂u   （JVP/VJP で陽に構成せず計算）
```

デノイジング step t は「T 個の独立な L-horizon 制御問題を連鎖させる機構」として扱う。
これなら B が実在するので LQR が解け、しかも 1 forward pass 内で閉ループになる（今回の 1-call 遅延問題も消える）。

### 2.2 【致命的】固定方向の加算は VLA で効かないことが既知

DiMaS の主張は明快で、**線形デコード可能性 ≠ 線形ステア可能性**。今回の `Δ X_raw を単位ベクトル化 → α=40 倍 → 加算` はまさに古典的線形 steering であり、C2/C3/C4 が区別できなかったことは DiMaS の予測どおりである。

### 2.3 【重大】観測器がなく、介入が自分の目標を達成したかを測っていない

Buurmeijer の枠組みでは、介入は必ず観測器とペアで設計される。

```
u_ℓ = argmin ‖u‖²  s.t.  f_ℓ(x_ℓ + u) ∈ D
→ 線形観測器 f_ℓ(x)=W_ℓ^T x + b_ℓ、D=[ζ_min, ζ_max] なら閉形式：
   u_ℓ = (ζ_target − ζ_ℓ) · W_ℓ / ‖W_ℓ‖²
```

これは「介入後に観測特徴が目標区間に入る」ことをハード制約として保証する。
**つまり task success とは独立に「介入が成功したか」を測る内側の指標が手に入る。**
今回の検証には、この内側の指標が完全に欠けていた（success_rate が床に張り付いた時点で何も測れなくなったのはこのため）。

### 2.4 【重大】注入層と α の選び方が逆

Buurmeijer は「摂動は浅い層で効き、深くなるほど効かない。理由は表現の L2 ノルムが深さとともに増大するから」と明示している。28 ブロック中の Blk-13 で、しかも α を絶対値で固定した設計は、この効果を統制していない。

**修正**：層 ℓ × デノイジング step t の 2 次元グリッドで、`‖u‖/‖x_ℓ‖` を一定にした相対強度スイープを行う。

### 2.5 【重大】contrastive pair を使っていない

WA-LQR / DiMaS / Buurmeijer いずれも、**1つの因子だけが異なる matched pair** から方向を作る。

```
d_{l,t,τ}^(n) = x_{l,t,τ}^(ξ_n^+) − x_{l,t,τ}^(ξ_n^-)
a_{l,t} = (1/N·H_a) Σ_n Σ_τ d_{l,t,τ}^(n)
```

今回の kNN フローライブラリは「成功エピソードの局所平均フロー」であって contrast ではない。
同一シーン・同一 seed・同一ノイズで実プロンプト vs ダミープロンプトの forward pass を取れば、**「言語が作っている差」そのもの**が d として得られる。これが前回レビューで要求したオラクル介入である。

### 2.6 【重大】D 空間が記憶特徴に支配されている疑い

SAE 論文の数字（π0.5/LIBERO で 98.43%、より多様な DROID でも 94.92% が記憶特徴）は、
「エピソードをプールして PCA した低次元多様体」が抽象的な行動構造ではなく **どのデモを再生中か** を符号化している可能性を強く示唆する。相関次元 1.4〜2.7 という低次元性も、「進行度＋エピソード同一性」で説明されうる。

### 2.7 【重大】最も帯域の広い介入点（初期ノイズ）を使っていない

UniSteer の Proposition 1：速度場が Lipschitz なら `G_θ(s,·): R^d → R^d` は**全単射**。
つまりノイズ空間は「任意の行動チャンクに到達できる」ことが保証された制御インターフェースである。中間層活性への加算とは帯域が根本的に違う。

### 2.8 steering ターゲットが文献の到達点より一段も二段も上

5本が実際にステアできたもの：

- Buurmeijer: グリッパー開閉、EE 高さ、EE 速度（低次特徴）— **抽象的意味特徴（アフォーダンス、タスク目標）は future work と明記**
- WA-LQR: カメラ・グリッパー初期位置・視覚ノイズという **nuisance/robustness 特徴**
- SAE: 運動プリミティブと一部の意味的性質、ただし general と判定された少数の特徴のみ
- UniSteer: 人間の修正行動そのもの（教師信号あり）

今回の目標「言語なしでタスク全体を自律駆動」は、この中で**誰も到達していない最上段**である。
段階を作らずに最上段だけを検定したことが、床効果に張り付いた構造的原因。

### 2.9 Cosmos Policy 固有の資源を使っていない

Cosmos Policy は行動だけでなく **future state 画像と value（期待累積報酬）を latent frame として同時生成**し、test-time planning ができる。
「エネルギー場の谷を深くする」という design.md の仮説は、手作りの KDE ではなく**モデル自身の value ヘッド**で実装するのが自然かつ強力である。

## 3. 推奨する検証プログラム

Stage 0→5 の順で、**各段が次段の前提を保証する**構成にする。各段に「これが出なければ次に進まない」ゲート条件を置く。

---

### Stage 0：Steerability 監査（GPU軽、ロールアウト不要）

**目的**：どこに注入すべきかをデータから決める。現行の「Blk-13, k=(0,1)」という恣意的選択を置き換える。

**手順**（WA-LQR §4 をそのまま Cosmos-Policy/RoboCasa に適用）

1. matched contrastive pair を作る。1 因子だけを変え、seed・シーン・ノイズは固定する。

   | 対比集合 | ξ⁺ | ξ⁻ | 何を測るか |
   |---|---|---|---|
   | **L**（言語） | 実プロンプト | ダミープロンプト | **言語が作る差＝オラクル方向** |
   | **T**（タスク特異性） | "pick and place" | 他タスク指示 | 言語の選択情報 vs 発火情報 |
   | **P**（フェーズ） | grasp フェーズ | approach フェーズ | **既存の phase ラベルがそのまま使える** |
   | **G**（グリッパー） | 開 | 閉 | 低次特徴（Buurmeijer 再現） |
   | **S**（成否） | 成功ロールアウト | 失敗ロールアウト | 既存の検証との接続 |

2. 各 pair について DiT 活性を取得し、token 位置と action-chunk timestep で平均プーリング → `x̄ ∈ R^D`。
3. 差分 `d_k = x̄_k^+ − x̄_k^-` の集合に PCA、**上位3主成分**に射影。
4. 3次元で線形 SVM を当て、**平均ヒンジ損失**を分離性スコアとする（0=完全分離、1=ランダム）。
5. これを **(層 ℓ) × (デノイジング step t)** の全格子で計算しヒートマップ化。

> 高次元のまま SVM を当てると N≪D で自明に分離するため無意味。低次元射影が必須。

**ゲート条件**：少なくとも 1 つの (ℓ, t) でヒンジ損失が十分低いこと。
WA-LQR の結果からして Cosmos-Policy では出るはずである。出なければ活性取得のパイプラインを疑う（tokenプーリング、chunk 平均、正しい residual stream を取れているか）。

**副産物**：この段階で「言語が作る差」の主部分空間が得られる。前回レポートで問題にした「注入ベクトルが単一の massive activation 次元に collapse していないか」も、この部分空間と比較すれば即判定できる。

**特筆すべき知見**：WA-LQR は「同じ摂動に対応する潜在表現が全タスクで共有されているわけではないが、**特定のタスクの組み合わせは特徴表現を共有する**」と報告している。したがって「PnPCounterToCab で作った方向が CoffeePressButton で効くか」は事前にクラスタリングで判定できる。タスク横断の転移は無条件には期待できない。

### Stage 1：Positive control — ノイズ逆変換による能力上限の確定

**目的**：「この方策に対して、行動を所望の値に書き込むことは可能か」を先に確定させる。ここが通らなければ以降すべての否定的結果は解釈不能。

**手順**（UniSteer §4.1 の適応）

Cosmos Policy は flow matching ではなく EDM（5 step、σ: 80.0→42.3→21.0→9.6→4.0）だが、決定論的サンプラであれば同じ論法が使える。

1. 各サンプラ step の逆写像を不動点方程式として書く：`x = y − Δt·v_θ(x, t_k, s)`、写像 `g_y(x)`。
   縮小条件（EDM の場合は step size と局所 Lipschitz 定数の積 < 1）を数値的に確認する。
2. 教師成功エピソードの行動チャンク `a*` から出発して逆向きに K step 反復し、初期ノイズ `ẑ` を復元。
   反復回数 M は 4/8/16/32 でスイープ（UniSteer では 16 で再構成 MSE が飽和）。
3. **再構成テスト**：`G_θ(s, ẑ)` が `a*` を再現するか（action chunk MSE で測定）。
4. **オラクル介入テスト**：ダミープロンプト条件で `ẑ` を初期ノイズとして与える。
   - 行動が `a*` を再現するか
   - **実際に環境で実行してタスクが完遂するか**

**ゲート条件**：3 が MSE < 1e-3 程度で通ること。
**期待される最重要の結果**：4 が通れば、**「言語なしでタスクを駆動する」ことが原理的に可能**であることが確定し、前回までの否定的結論は「手法の失敗」として正しく位置づけられる。

**注意点**：Cosmos Policy は行動を「video model の latent diffusion 過程内の latent frame」として生成する。DEC（latent→action のデコード）の可逆性を別途確認する必要がある。DEC が非可逆なら、逆変換のターゲットを action ではなく **latent frame** に置く。

### Stage 2：言語なし駆動の実装 — 観測条件付きノイズアクター

Stage 1 が通ったら、これが**本命の手法**になる。design.md の目標（言語に依存せず感覚から行動を駆動する）を、文献的に裏付けのある形で実装したものになる。

1. 成功エピソード全体について、各 call の行動チャンクをノイズ逆変換 → `{(o_t, ẑ_t)}` のデータセットを作る。
2. **観測のみを入力とする軽量ノイズアクター** `ψ_φ(z | o)` を教師あり学習（`L = ‖ψ_φ(o) − ẑ‖²`）。方策本体は完全に凍結。
   - UniSteer の noise representation dim は 50、actor は [1024,1024,1024] MLP + 小さな CNN。極めて軽量。
3. 推論時：ダミープロンプト（または零埋め込み）＋ `z = ψ_φ(o_t)` でロールアウト。
4. 必要なら報酬でオンライン改善（UniSteer は SFT→RL の順が最良と報告。逆順は RL で得た分布を上書きして劣化する）。

**この設計の意味**：「観測ストリームだけから、事前学習済み生成方策の生成過程を条件付ける」ものであり、
言語を経由しない感覚運動結合の直接的な実装になる。しかも方策の重みは触らない。

**評価**：C0（実プロンプト）を上限、C1（ダミー・介入なし）を下限とし、この手法がどこまで届くか。
**これが前回の検証で欠けていた「上限と下限の間で測る」構図そのものである。**

### Stage 3：活性介入の作り直し — 観測器＋最小ノルム制御＋分布輸送

Stage 2 と並行して、活性空間側の介入も文献水準に引き上げる。3 段階のアップグレード。

**3-A. 観測器ベースの最小ノルム介入（Buurmeijer）**

Stage 0 の contrastive 集合から線形プローブ `f_ℓ(x)=W_ℓ^T x + b_ℓ` を学習し、

```
ζ_ℓ = f_ℓ(x_ℓ)
u_ℓ = (ζ_max − ζ_ℓ)·W_ℓ/‖W_ℓ‖²   if ζ_ℓ > ζ_max
    = (ζ_min − ζ_ℓ)·W_ℓ/‖W_ℓ‖²   if ζ_ℓ < ζ_min
    = 0                            otherwise
```

- プローブのロバスト性を必ず先に確認する（`‖f_ℓ(x+ε) − f_ℓ(x)‖ < δ`）。Buurmeijer は Remark 1 でこれを明記しており、OpenVLA の delta yaw では実際に非ロバストだった。
- **必ず制約充足率と閉ループ成功率を同一プロットで報告する**。Buurmeijer が強調している通り、片方だけの評価は無意味。
- まずは低次特徴（グリッパー開閉、EE 高さ、EE 速度）で再現を取る。ここが再現できなければ実装が疑わしい。

**3-B. 分布輸送 steering（DiMaS）**

固定方向シフトを、活性**分布**の輸送に置き換える。ガウス近似なら Monge 写像が閉形式で得られる：

```
T(x) = μ_t + A(x − μ_s),   A = Σ_s^{-1/2}(Σ_s^{1/2} Σ_t Σ_s^{1/2})^{1/2} Σ_s^{-1/2}
```

- source = ダミープロンプト条件の活性分布、target = 実プロンプト条件の活性分布。
- 共分散が高次元で不安定なので、Stage 0 で得た低次元部分空間内で推定する。
- DiMaS は entropic OT / low-rank Sinkhorn 系の道具立てを使っており、POT ライブラリで実装可能。
- **ablation**：平均シフトのみ（= 従来の ActAdd）vs 全輸送写像。DiMaS の主張が正しければここで明確な差が出る。

**3-C. 層方向 LQR（WA-LQR）**

「フローへの介入」という design.md の着想を、正しい力学系の上で実装する。

1. 各 (ℓ, t) で contrastive 方向の行列に **streaming randomized SVD** をかけ、正規直交基底 `V_{l,t} ∈ R^{d_x×d_z}`（`d_z ≪ d_x`）を得る。射影 `P_{l,t}=V_{l,t}^T` は chunk timestep 間で共有。
2. 特徴強度 `β^z_{l,t,τ} = (v^z_{l,t})^T z_{l,t,τ}`、目標 `β* = λ‖e^z_{l,t}‖`、追従誤差 `α_{l,t,τ} = β* − β^z`。
3. 各 (τ, t) について層方向に L step の LQR を解く。制御コストに **chunk index による減衰スケジュール** を入れる：
   `r(τ) = min(R_final, R_init·exp(τ/τ_R))` → 早い chunk ほど強く steer し、進むにつれ介入が消える。
4. Riccati 再帰で `O(L·d_z³)`。十分高速。

**この 3 手法の比較自体が論文になる**：同一タスク・同一注入点で
「固定方向加算 / 観測器＋最小ノルム / 分布輸送 / 層方向 LQR」を並べ、
DiMaS の主張（線形ステア不可）と WA-LQR の主張（フィードバックが効く）を Cosmos-Policy × RoboCasa で検証する。

### Stage 4：一般特徴 vs 記憶特徴の分離（SAE）

「D 空間はエピソード記憶を測っているだけではないか」という疑いに正面から答える。

1. Blk 活性（Stage 0 で分離性が高かった層）に **BatchTopK SAE** を学習。閉ループのロールアウト収集から。
2. SAE 論文の指標で各特徴を **general / memorized** に分類。
3. **general と判定された特徴のみ**で steering 部分空間を構成し、Stage 3 の介入を再実行。
4. 対照として memorized 特徴のみの部分空間でも実行。

**予測**：memorized 部分空間での介入は「別のデモの再生」を引き起こし、general 部分空間での介入は運動プリミティブを変える。これが分離できれば、前回の「D 空間で成功/失敗が分離する」という知見の正体も判明する。

---

### Stage 5：現象学的問いを検定可能な形に落とす

design.md の「ハサミと切ることの不可分性」は、上の道具立てで初めて操作的に検定できる。

**再定式化**：探すべきは「観測特徴」でも「行動特徴」でもなく、
**(対象の視覚的存在) AND (その対象に固有の運動) の連言でのみ発火する general な SAE 特徴**である。

検定手順：

1. SAE 特徴のうち general と分類されたものについて、以下の 4 条件での発火率を測る。

   | 条件 | 対象が視野内 | 対応する運動を生成中 | 期待 |
   |---|---|---|---|
   | A | ○ | ○ | 高発火 |
   | B | ○ | × | 低発火 |
   | C | × | ○ | 低発火 |
   | D | × | × | 低発火 |

   A ≫ B, C を満たす特徴が「連言特徴」＝ 感覚運動結合の不変量の候補。
   単に A,B が高いなら物体特徴（表象主義的）、A,C が高いなら運動特徴（表象主義的）。
   **この 2×2 設計が、design.md の主張を初めて反証可能にする。**

2. 因果テスト：連言特徴を、対象が視野内にある状況でダミープロンプト下にクランプ（SAE デコーダ方向、または 3-A の setpoint 制御）。
   対応する運動が誘発されるかを **graded な指標**で測る。

3. 転移テスト：新しいシーン・新しい配置で同じ特徴が同じ役割を果たすか（DiMaS はタスク非類似度を上げていったときに行動制御がどこで転移しどこで弱まるかを特徴づけている。この軸を踏襲する）。

## 4. Cosmos Policy 固有の未活用リソース

### 4.1 value ヘッドを「エネルギー場」として使う

Cosmos Policy は future state 画像と value（期待累積報酬）を latent frame として同時生成し、
test-time planning に使える設計になっている。

design.md の「エネルギー場の谷を人工的に深くする」は、8次元 PCA 空間の Gaussian KDE ではなく
**モデル自身が学習した value 予測**で実装するのが自然である。

- `E(D) = −log p(D)`（手作り、curse of dimensionality で密度として無意味）
  → `E = −V(o, a)`（モデル自身の学習済み価値、意味論的に正しい）
- steering は「value 勾配方向への活性介入」または「value による行動チャンク選択」として実装できる。

### 4.2 最も安価で強力なベースライン：value ガイド付き best-of-N

**ダミープロンプト下で行動チャンクを N 本サンプルし、value ヘッドで選択する。**

- これで成功率が上がるなら、**モデル内部にはタスク構造が保持されており、欠けているのは表現ではなくサンプリングの条件付け**であることが示される。
- 実装は数十行。GPU 数時間。
- 前回の検証で success_rate が全条件 0.00 に張り付いた状況を打開する最短経路でもある。

### 4.3 video モジュール vs action モジュール

WA-LQR は LingBot-VA に対して action モジュールと video モジュールで**別々に** steering を評価している。
Cosmos Policy も両方の stream を持つ以上、**どちらに介入するかは独立した設計変数**である。今回は action-token stream の 1 ブロックしか触っていない。

関連して、World Pilot (2606.12403) は Cosmos の中間デノイジング状態から取った **future latent** を steering の手がかりとして使い、LIBERO-Plus で改善を報告している。future latent は「これから何が起きるか」というモデル自身の予測であり、design.md の「動態」に最も近い内部表現である。

## 5. 実験設計の作法（前回の反省を反映）

1. **必ず内側の指標を持つ**。「介入が観測特徴を目標に到達させたか」を task success とは独立に測る。Buurmeijer の枠組みでは制約充足率がこれにあたる。
2. **制約充足率と閉ループ成功率を同一プロットに描く**。片方だけの改善は成果ではない。
3. **床のない従属変数**を主指標に：対象物までの最小距離、接触イベント数、把持試行、phase 到達率。
4. **chance level を必ず測る**：ゼロ行動、ランダム定行動。
5. **matched pair・matched seed**を徹底。contrastive 方向の質はここで決まる。
6. **相対強度**で介入量を定義：`‖u‖/‖x_ℓ‖`。層ごとにノルムが違うため絶対値の α は比較不能。
7. **事前予測 → 検証**の構造にする。Stage 0 の分離性スコアから steerability を予測し、Stage 3 の結果と照合する。WA-LQR がこの構造で成功しており、査読上も強い。

## 7. 期待される論文の形

Stage 0–3 が揃うと、以下の主張を持つ論文になる。

> **World Action Model（Cosmos Policy）において、抽象的なタスク行動は言語なしに駆動できるか。**
> 我々は 4 つの介入インターフェース（中間層活性の線形加算、観測器ベース最小ノルム制御、活性分布輸送、初期ノイズ）を同一のタスク・同一の評価軸で比較し、
> **介入の帯域はインターフェースによって桁で異なること**、
> 具体的には線形活性加算では駆動できない一方、ノイズ空間の条件付けでは言語なしでタスク完遂が可能になることを示す。
> さらに、活性空間の低次元分離性が各インターフェースの有効性を事前に予測することを示す。

これは DiMaS の「線形にステアできない」という主張を Cosmos Policy で追試しつつ、
UniSteer のノイズインターフェースが代替になることを示す構成であり、
既存の 5 本のいずれとも重複しない位置に立てる。

さらに Stage 4–5 を足せば、
**「感覚運動が結合した不変量は SAE 特徴として実在するか、そしてそれは記憶ではなく一般的か」**
という、design.md 本来の問いに対する初の実証的回答になる。

## 付記：注意すべき点

- **タスク横断の転移は無条件には期待できない**。WA-LQR は「同じ摂動に対応する潜在表現が全タスクで共有されているわけではない」「ただし特定のタスクの組み合わせは特徴を共有する」と報告している。フェーズ5で CoffeePressButton / CloseDrawer に同じベクトルを流用した設計は、この意味でも根拠が薄かった。転移の可否は事前にクラスタリングで判定すること。
- **抽象的意味特徴の steering は依然として未踏**。Buurmeijer は明示的に future work としている。したがって Stage 5 は「うまくいかない可能性が十分ある挑戦的な段」として位置づけ、Stage 1–3 の成果とは独立に評価できるようにしておく。
- 本プランは 2026年7月までに公開された 5 本に基づく。着手前に各論文の公開コード（DiMaS: github.com/pegah-kh/dimas、WA-LQR: github.com/trustworthyrobotics/steering_robustness_WAMs）を確認すること。WA-LQR は Cosmos-Policy での実装が公開されているため、Stage 0 と Stage 3-C は再実装ではなく適応で済む可能性が高い。
