# 検証指示書：感覚運動結合動態の不変量に基づくアクション駆動の検証

## 1. 背景と検証の基本方針
本検証の目的は、Cosmos Policyにおいて、言語（プロンプト）に依存せず、ニューロンまたは潜在表現から「抽象的アクション」を駆動できるかを検証することである。
ただし、過去の検証（§1〜6）により、本モデルの潜在空間には「離散的・記号的なスキルアトラクタ」は存在せず、低次元の連続的な進行多様体が存在することが判明している。また、特定のベクトルを加算するだけの静的な介入（mid-layer steering）はタスクを破壊するだけ（必要条件のみ）であった。

従って本検証では、現象学・エナクティヴィズムに基づき、**「状態（Observation/Latent）」と「行動（Action）」を分離して扱う表象主義的アプローチを破棄**する。代わりに、**「感覚と運動の結合動態の系列（Dynamics）」自体を一つの数学的対象として埋め込み、その空間上に距離構造やエネルギー場（ベクトル場）を定義する。** そして、その場における「動態的不変量（アトラクタ構造の谷や連続的なフローチャネル）」を特定し、そこに沿った動的な介入を行うことでアクションが駆動されるかを検証する。

## 2. 検証フェーズと実装手順

### フェーズ1：感覚運動の「結合動態（Dynamics）」の空間埋め込み
静的な潜在表現 $Z_t$ を分析するのではなく、時間的動態を含む系列を一つの点として写像する空間 $\mathcal{D}$ を構築する。

*   **実装指示:**
    1.  成功エピソードのロールアウトデータから、時間窓 $\tau$ （例：$\tau = 3 \sim 5$ ステップ）を設定する。
    2.  各時刻 $t$ における「潜在表現のフロー（$V_t = Z_{t+1} - Z_t$）」と「行動出力の変化（$\Delta A_t$）」、および「視覚特徴の勾配（Attention mapの時間微分など）」の結合テンソルを作成する。
    3.  遅延座標埋め込み（Delay Coordinate Embedding / Takens' Theorem）の概念を応用し、系列 $S_t = [Z_{t-\tau}, \dots, Z_{t}, \dots, Z_{t+\tau}]$ を単一の動態ベクトル $D_t \in \mathcal{D}$ に射影するエンコーダ（線形PCA、または自己符号化器）を学習させる。
    4.  **【重要】** ここで得られた $\mathcal{D}$ 空間は、「ハサミ（視覚）」と「切る（行動）」が不可分な動態として表現された空間となる。

### フェーズ2：場（Field）とエネルギー構造の定義
これまでの検証（§5.4, 5.5）で確認された「実質一桁台次元の低次元多様体」の上に、アトラクタ構造を定義する。

*   **実装指示:**
    1.  空間 $\mathcal{D}$ 上に、データポイントの密度に基づくエネルギー関数 $E(D)$ を推定する。Score matching（拡散モデルのスコア関数の推定）の技術を流用し、データ多様体に引き込むベクトル場 $\nabla \log p(D)$ を計算せよ。
    2.  過去の検証（§5.7 DMDヤコビアン解析）で示された「幾何学的逸脱」と「力学的不安定性」をこの空間で再評価する。成功軌跡の周辺ではエネルギーの谷（安定したチャネル）が形成され、失敗軌跡はリッジ（尾根）を越えて発散しているかを確認する。
    3.  ここで発見すべき「不変量」は、点ではなく**「滑らかなベクトル場の流れ（フローチャネル）」**である（以前確認された「フェーズに紐づいたstickiness」の連続表現）。

### フェーズ3：「不変量」への動的介入（Dynamic Steering）によるアクション駆動
過去の検証における介入（§10.3 real_v方向への一律加算）がタスク破壊に留まった理由は、介入が「状態」に対する静的な摂動であり、力学系の多様体から直交方向に状態を弾き飛ばしたためである。今回は**「フロー（場）」に対して介入**する。

*   **実装指示:**
    1.  言語プロンプト（条件付け）を無効化、またはダミー（「天気の話題」など、過去の検証§10.4で非特異的だったもの）に設定する。
    2.  **Vector Field Steering (動的介入):** 推論時の各ステップにおいて、潜在表現 $Z_t$ に対して静的なベクトルを足すのではなく、フェーズ2で特定した**「対象の動態的不変量（特定のアクション動態に対応するベクトル場のフロー方向）」へと速度ベクトルを書き換える**介入を行う。
        *   式：$Z_{t+1} = Z_t + \alpha \cdot \text{Proj}_{\text{manifold}}(V_{\text{target\_dynamics}})$
        *   ※多様体（進行多様体）の接平面への射影（Projection）を必ず行い、過去の検証（§5.6）で起きた「多様体からの逸脱（＝失敗）」を防ぐこと。
    3.  これにより、例えば「対象物（ハサミ）が視界に入ったとき、プロンプト無しでも『切る』という動態アトラクタに引き込まれ、自律的にそのアクション軌道が生成されるか」を検証する。

### フェーズ4：評価指標の設定

*   **実装指示:**
    以下の定量指標を用いて、介入効果を評価せよ。
    1.  **動的因果効力（Dynamic Causal Efficacy）:** 動的介入を行った際の出力行動（Action）の軌跡が、ターゲットとした動態の教師行動軌跡とどの程度一致するか（Frechet DistanceまたはDTW距離で測定）。
    2.  **多様体逸脱度（Manifold Deviation）:** 介入中の潜在軌跡が、§5.6で定義した成功エピソードの進行多様体から逸脱していないかをチェック。逸脱が起きてタスクが破壊された場合は、介入ベクトルが不変量に沿っていなかった（静的すぎた）とみなす。
    3.  **環境・感覚フィードバックへの従属性:** 介入中、環境からの観測（$O_t$）を変化させた際、出力アクション（$A_t$）がReactiveな一定出力にならず、不変量を維持したまま柔軟に調整されるか（感覚運動随伴性が保たれているか）。

## 3. 期待される結果（仮説）とCoding Agentへの心構え

*   Coding Agentへ：これまでの検証から、「Cosmos Policyは言語指示に対しては汎用的に反応するが、潜在空間自体は『進行度』という低次元の連続多様体を形成している」ことが分かっています。
*   したがって、特定のニューロンを探してON/OFFするような還元主義的な探索はしないでください。
*   求めるべきは**「ハサミと切る行為の不可分な結合」のような、ObservationとActionがペアとなって初めて安定する力学系（ダイナミクス）の抽出**です。
*   仮説として、「プロンプトが無くても、特定の感覚入力に対して『エネルギー場の谷』を人工的に深くしてやる（＝ベクトル場介入）ことで、モデルが勝手にその感覚運動ループ（行為）に引き込まれる現象」が観測されれば、本検証は大成功です。

## 4. この検証案を考えるにあたって参照した思想

個人メモ：PID-NNにおける「抽象行動表現自体の空間の獲得」という以前からやりたい話について．哲学的には以前から現象学，具体的にはメルロ=ポンティの運動的志向性と関連すると思っていたが，より現代的にはエナクティヴィズムや感覚運動随伴性理論に対応しているっぽい．つまり，我々が認識している「行動」は（あるいは行動でなくて一般的な認識も含む），あらかじめ離散的・記号的な単位として与えられた観測からのreactiveな出力ではなく，感覚と運動の結合動態の規則性のなかで安定する不変量として立ち現れる抽象である．したがって抽象行動表現の獲得とは，観測の符号化でも方策のパラメータ化でもなく，系列の動態自体を多様体として捉え，そこから不変量を表現空間として取り出す形として定式化できる．行動条件付けの現代的な世界モデルも，表れ方そのものから構成を考えるという現象学の立場から見ると，外的観測ストリームを符号化する時点で観測者の視点を暗黙に立てており，さらに現象学が否定した表象主義が残っている（最近の予測符号化と現象学を対応させようという議論も結局この点で行き詰まっている）．この表象主義から離脱するには，世界との関わりを含めた感覚運動の結合動態それ自体を一次的対象とし，その動態的不変量（アトラクタ構造など）として表現を定義するしかない．これはreactiveでも，現在の世界モデル化（観測ストリームの予測符号化）でも到達できないはずという仮説．昔中野くんが修士の時とかに言ってた例でいうと，例えばハサミという対象があった時に，観測ストリーム上の視覚特徴の塊として表現され，切るという行為は入力actionとして外から与えられる．つまり，「ハサミ」と「切る」が別々の変数として扱われる．しかし，本来ハサミの概念は切る動態と不可分であり，これらの感覚運動の一連の結合動態を一次的対象にして初めて，ハサミは本当にハサミという概念として現れる．つまりハサミという概念は，この動態的アトラクタの不変構造．結合動態を表現として扱うには，一連の動態を一つの数学的対象に写像する埋め込みを構成し，その対象の空間上に，対象間の近さを判定する場やエネルギー，距離構造を定義する．このとき表現空間は，埋め込み空間を場の構造で組織化したものになる．前者だけだったらWAMを軌道に拡張したときの内部構造とかに現れるかもしれないが，後者が足りない．だからPID-NNを考えている．
